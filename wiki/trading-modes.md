# 매매 모드

StockBot은 두 가지 매매 모드를 지원한다. 설정에서 언제든 전환 가능.

## 반자동 모드 (기본값)

```
신호 생성 → 텔레그램 승인 요청 → 사용자 응답 → 주문 실행
```

- 매매 신호 발생 시 텔레그램으로 승인 요청
- 사용자가 텔레그램에서 "승인"/"거부" 응답
- 승인 시 [[order-execution|주문 실행]], 거부 시 신호 폐기
- 응답 없이 타임아웃 초과 시 자동 폐기

**장점**: 최종 결정권 유지, 오신호 필터링
**단점**: 부재 시 기회 손실, 빠른 단타에서 지연

[[telegram-integration]] 참조.

## 완전 자동 모드

```
신호 생성 → 즉시 주문 실행 → 텔레그램 결과 알림
```

- 신호 발생 즉시 주문 실행
- 텔레그램으로 실행 결과만 통보
- [[risk-management|리스크 체크]] 통과 후 실행

**장점**: 빠른 진입, 부재 시에도 자동 운영
**단점**: 오신호 방어 없음, 모니터링 필수

## 모드 전환

DB `settings` 테이블의 `trading_mode` 키 변경:
```
semi_auto  → 반자동
full_auto  → 완전자동
```

웹 대시보드 설정 페이지 또는 REST API로 전환 가능.

**장중 전환 가능**: 즉시 적용 (진행 중인 신호는 기존 모드로 처리).

## 모의/실전 모드와의 관계

[[paper-vs-live|모의/실전 전환]]은 매매 모드와 독립적:
- `TRADING_ENV`: 모의(paper) vs 실전(live) — 실제 주문 여부
- `trading_mode`: 반자동 vs 완전자동 — 승인 프로세스 여부

두 설정의 조합으로 4가지 운영 방식 가능.

## 대시보드 표시

실전 모드: 빨간 배지, 모의 모드: 초록 배지로 현재 환경 명확히 표시.
