# 공공 데이터 소스

[[kis-api|한투 API]] 외 보조 데이터 소스들. 장전 수집에서 활용.

## 공공데이터포털 (data.go.kr)

**역할**: 장전 1차 스크리닝의 핵심 소스.

- API: 금융위원회_주식시세정보
- 제공 데이터: 전 종목 종가/시가/고가/저가/거래량/시총/상장주식수
- 수집 주기: 장전 08:00 일괄 (6회 호출, 약 3.7초)
- Rate Limit: 일 1,000건 (여유 있음)
- 환경변수: `DATA_GO_KR_API_KEY`
- **한계**: ETF 미포함 → ETF는 별도 처리 필요

### 수집 방식
```
페이지당 500개 × 6페이지 = 3,000개 (KOSPI + KOSDAQ 약 2,880종목 커버)
```

## Open DART API

**역할**: 재무 기초 데이터 — 보조 스크리닝 팩터.

- 제공 데이터: 매출/영업이익 등 분기 재무제표
- 수집 주기: 분기 갱신 시에만 (실시간 아님)
- Rate Limit: 일 10,000건
- 환경변수: `DART_API_KEY`
- **한계**: 실시간 공시는 지연 불확실 → 속보 용도 부적합

## 네이버 검색 API

**역할**: 뉴스 센티멘트 분석 — 보조 팩터.

- 제공 데이터: 종목 관련 뉴스 제목/링크
- 수집 주기: 일 1~2회 배치
- Rate Limit: 일 25,000건
- 환경변수: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
- **한계**: 속보 대형주 외 1시간+ 지연 → 스크리닝 보조로만 활용

## API 우선순위

[[data-collection-flow|데이터 수집 흐름]]에서의 역할:

1. **핵심**: 공공데이터포털 (1차 스크리닝 팩터 — 거래량/가격/시총)
2. **보조**: DART (재무 건전성 필터)
3. **보조**: 네이버 (센티멘트 보정, 가중치 낮음)

## 추가 소스 연동 원칙

PRD에 따라, 새 API 연동 전 반드시 테스트 우선:
- Rate Limit 실측
- 데이터 품질/지연 검증
- 기존 스크리닝 팩터 대비 유의미한 개선 여부 확인
