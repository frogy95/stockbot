CLAUDE.md, 규칙, 훅, 에이전트, 커맨드 간의 중복/상충/컨텍스트 낭비를 감사한다.

## 목적

Claude Code 세션에서 불필요하게 로드되는 중복 컨텍스트를 찾아내고, 문서 간 상충을 발견하여 수정한다.
컨텍스트 윈도우 효율성을 높이고 에이전트 동작의 일관성을 보장한다.

## 감사 대상 파일

1. `CLAUDE.md` — 전역 프로젝트 지침 (매 세션 로드)
2. `.claude/rules/*.md` — 경로별 규칙 (파일 접근 시 로드)
3. `.claude/hooks/*.sh` — PreToolUse/Stop 훅 (도구 호출 시 실행)
4. `.claude/hooks/lib/*.json` — 훅 설정 데이터
5. `.claude/agents/*.md` — 에이전트 정의 (에이전트 호출 시 로드)
6. `.claude/commands/*.md` — 슬래시 커맨드 (커맨드 실행 시 로드)
7. `docs/dev-process.md` — 프로세스 Single Source of Truth

## 감사 절차

### 1단계: 파일 수집

위 감사 대상 파일을 모두 읽는다.

### 2단계: 중복 분석

**컨텍스트 낭비 기준**: 동일한 정보가 2곳 이상에 구체적으로 기술되어 있는 경우.

체크 항목:
- CLAUDE.md와 rules/*.md 간 내용 중복 (CLAUDE.md는 참조 링크만 유지해야 함)
- CLAUDE.md와 dev-process.md 간 프로세스 상세 중복
- 에이전트 간 동일 절차 반복 (deploy.md 아카이빙 등 — 독립 실행을 위한 최소 중복은 허용)
- rules/*.md와 dev-process.md 간 기준/목록 중복

**허용되는 중복**:
- 에이전트가 독립 실행되기 위한 최소 컨텍스트 (PR 대상 브랜치, 참조 링크)
- 훅이 자체 판단을 위해 필요한 임계값 (doc-rules.json의 hotfix 기준 등)

### 3단계: 상충 분석

체크 항목:
- 커맨드/에이전트의 bash 명령이 bash-guard 훅 패턴과 충돌하는지
- 브랜치 생성 기준점이 문서 간 일치하는지 (develop vs main)
- 에이전트 간 역할 경계가 명확한지 (sprint-close vs sprint-review)
- rules의 paths 필터가 실제 트리거 대상과 맞는지
- doc-rules.json의 검증 기준이 dev-process.md와 일치하는지

### 4단계: 컨텍스트 효율성 분석

체크 항목:
- CLAUDE.md에 상세 내용이 인라인되어 있는지 (참조로 대체 가능한 경우)
- rules/*.md에 다른 문서를 그대로 복사한 내용이 있는지
- 에이전트 정의에 다른 에이전트/문서의 내용을 그대로 옮겨 적은 부분이 있는지
- 빈 참조("→ X 참조"라고만 쓰고 내용이 없는 줄)가 있는지

### 5단계: 보고서 출력

다음 형식으로 사용자에게 보고한다:

```
## 컨텍스트 감사 결과

### 상충 (Critical)
| # | 위치 A | 위치 B | 내용 | 영향 |
|---|--------|--------|------|------|

### 불필요한 중복
| 위치 A | 위치 B | 중복 내용 | 권장 조치 |
|--------|--------|----------|----------|

### 컨텍스트 효율성 개선
| 파일 | 현재 | 권장 | 절감 효과 |
|------|------|------|----------|

### 허용된 중복 (참고)
| 위치 | 이유 |
|------|------|
```

### 6단계: 수정

사용자가 승인하면 보고서의 권장 조치를 순서대로 실행한다:
1. Critical 상충부터 수정
2. 불필요한 중복 제거 (참조 링크로 대체)
3. 컨텍스트 효율성 개선

## 원칙

- **Single Source of Truth**: 프로세스 상세는 `docs/dev-process.md`, 경로별 규칙은 `rules/*.md`, 에이전트 동작은 `agents/*.md`에만 존재해야 한다.
- **CLAUDE.md는 인덱스**: 상세 내용이 아닌 참조 링크와 고유 규칙(언어, 체크리스트 형식 등)만 유지한다.
- **에이전트는 자족적**: 다른 에이전트를 읽지 않으므로, 독립 실행에 필요한 최소 정보는 중복을 허용한다.
- **훅과 커맨드는 정합성 필수**: bash-guard가 차단하는 패턴을 커맨드가 사용하면 안 된다.
