## Phase 9: Z-score + VWAP + 가속도 통합 (4 Sprint, 데이터 의존성 재검토)

### 핵심 재검토 결과
- **VWAP 실시간**: 당일 장중 누적만 필요 → 과거 축적 불필요, 즉시 착수 가능
- **Z-score (total_vol)**: KIS 과거 분봉 백필(대안 A) + 점진 활성화(대안 C) 조합
- **대안 B 기각**: 시뮬레이션은 Phase 10이 검증할 가정과 순환 논리
- **점진 활성화 구간 조정**: 5/10/20일 → 10/15/20/30일 (최리스크 R1)
  - 가중치: 0%(<10) / 10%(10-15) / 30%(15-20) / 60%(20-30) / 100%(30+)

### Sprint 구성
- Sprint 0: 데이터 인프라 + KIS 백필 + 5분봉 가속도 (Phase 8 Sprint 1·2 완료 후 즉시)
- Sprint 1: Z-score 엔진 (점진 활성화)
- Sprint 2: VWAP 엔진 + 가격 포지션 (Sprint 0 완료 후 병행 가능)
- Sprint 3: 백테스트 데이터셋 + REST API (TimeSeriesSplit 필수)
