Phase 2 (데이터 수집 + 종목 스크리닝) 계획 수립 완료 (2026-03-29).

**Why:** Phase 1의 한투 API 클라이언트/토큰/스로틀러 기반 위에 실제 데이터 수집 및 스크리닝 파이프라인 구축이 필요.

**How to apply:**
- Sprint 3개 분할: Sprint 1(핵심 수집), Sprint 2(스크리닝), Sprint 3(보조 데이터+통합)
- 정프로 권고로 DART/네이버를 Sprint 3으로 분리 (Sprint 1~2 독립 배포 가능)
- 핵심 파라미터: 거래량 200%+, 등락률 +1~+7%, 후보 30종목 상한, WS 35종목, 체결강도 5분 최소 누적
- 스코어링: 순위 기반 백분위, 5팩터 동일 가중, 상위 20% 통과
- Phase 1 미해결 #9~#13 Sprint 1에서 해소
- 전문가 5명: 정프로(PO), 최리스크(리스크), 김단타(단타), 윤에이피(API), 박퀀트(퀀트)
