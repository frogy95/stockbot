Phase 0.5 계획 수립 완료 (2026-03-29).

**Why:** 4개 외부 API(한투/네이버/DART/텔레그램) 검증이 Phase 1 이후 아키텍처 결정의 전제.

**How to apply:**
- Sprint 0(사용자 수동): API 키 발급 + .env 설정
- Sprint 1: API 4종 탐색/검증 (한투 > 텔레그램 > 네이버 > DART 순서)
- 전문가 4명 검토 완료: 정프로(PO), 최리스크(리스크), 윤에이피(API), 김단타(단타)

**핵심 주의사항 (전문가 검토 결과):**
1. 한투 에러 시나리오 5가지 필수 검증 (최리스크)
2. 장중(09:00~15:30) 테스트 반드시 포함 (김단타)
3. .env.example 업데이트 선행 필수 (윤에이피)
4. hashkey, tr_id 매핑, 호가단위 등 한투 추가 검증 항목 6개 (윤에이피)
5. 웹소켓 30분 유지 + 데이터 지연 측정 + 끊김 재연결 (김단타+최리스크)
