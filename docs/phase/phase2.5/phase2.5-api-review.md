## 2. 핵심 지적사항

### mst URL 안정성 — ⚠️
- KIS 공식 GitHub에서 참조하지만 SLA 보장 엔드포인트가 아님
- URL 구조 변경 전례 있음 → 환경변수 KIS_MST_BASE_URL로 분리 권고
- 다운로드 실패 시 재시도 3회, 10초 간격

### CP949 파싱 — ⚠️
- KOSPI와 KOSDAQ의 mst 파일 포맷이 다름 → 파서 분리 필수
- null padding 제거 순서: rstrip('\x00').rstrip()
- 더미 레코드(000000) 필터링 필요

### 갱신 시점 — ⚠️
- mst 파일은 전일 장 마감 후 15:30~17:00 갱신
- 신규 상장 종목은 상장일 당일 새벽 06:00~07:00 추가
- 08:10 이후 다운로드가 더 안전

### 폴백 전략 — ❌
권고 폴백 계층:
1. mst 다운로드 성공 → DB upsert
2. mst 실패 → 기존 stocks 테이블 ETF 유지 + 알림
3. DB에도 ETF 없음 (최초 설치) → 시드 데이터

### is_active 갱신 범위 오염 리스크
- 반드시 stock_type='ETF'로 scope 제한
- ETF 200개 미만이면 is_active 갱신 스킵 + 알림 (sanity gate)

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| ETF 마스터 갱신 시각 | 08:02 | **08:10** | mst 갱신 완료 여유 확보 |
| ETF 시세 수집 시각 | 08:05 | **08:15** | 마스터 갱신 완료 대기 |
| mst 다운로드 타임아웃 | 30초 | **60초** | KOSDAQ mst ~20MB, 서버 부하 시 느려짐 |
| ETF 최소 종목 수 경고 | 100 | **200** | 국내 ETF 700+종 |
| 시드 ETF 종목 수 | 30 | **50** | 주요 시리즈 커버 |
| 재시도 횟수 | (미정) | **3회, 10초 간격** | 일시적 502 대응 |
| mst URL | 하드코딩 | **환경변수** | URL 변경 대응 |

## 4. ETN 처리

- ETP 필드: 1=ETF, 2=ETN, 3=ELW (추정)
- stock_type='ETN' 별도 구분 권장
- ETN은 발행사 신용 리스크 → 매매 대상 제외 가능성

## 5. 최종 의견

아키텍처 방향 올바름. mst 다운로드 → ETF 필터링 → DB upsert는 업계 표준. 핵심 수정:
1. 폴백 계층 재설계 (시드 단독 → 기존 DB 활용)
2. 스케줄 시간 조정 (08:10/08:15)
3. KOSPI/KOSDAQ 파서 분리
4. sanity check 강화
