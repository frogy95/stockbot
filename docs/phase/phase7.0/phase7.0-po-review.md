## 2. 항목별 검증 결과

### P0 결함 — 즉시 수정
- **결함 #1 (가격 갱신 미연결)**: 이건 시스템의 존재 의의를 부정하는 수준. 손절/익절이 영구 불능이면 자동 매매 시스템이 아니라 자동 매수 시스템임. Sprint 1 최우선.
- **결함 #2 (체결 후 포지션 미생성)**: 주문이 체결되어도 포지션이 없으면 모니터링 자체가 불가. 결함 #1과 연쇄적.
- **추가 발견 (청산 미실행)**: `_monitor_positions_loop`에서 `check_exit_conditions` 결과를 로깅만 하고 실제 청산(매도 주문 + close_position) 미실행. 이것도 P0.

### P1 — 높은 우선순위
- **이중 주문 방지**: cancel 실패 시 return 추가는 간단. Sprint 1에 포함.
- **trade_strength_min 70→60**: KIS CTTR 기준 ~150 상당. 70이면 신호 거의 미발생. 60으로 낮춰야 Paper 모드에서 신호 발생 관찰 가능.
- **max_candidates 30→20**: WS 구독 한도 25와 맞추되, 여유분 5개를 두어 20이 적절.

### P3 — LIVE 전환 게이트
- Paper 5거래일 핫픽스 0건 + 신호 발생 3거래일 연속은 적절한 기준.
- 단, "신호 발생"의 기준을 명확히: **generate_signals에서 1건 이상 반환** (체결까지 불필요).

- **리스크**: Phase 7.0 없이 기존 Phase 7(5분봉)을 진행하면 LIVE 전환 불가. 선행 수정 필수.

- **범위 주의**: Sprint 1에 P0+P1만 집중. P2를 섞으면 리뷰 부담 증가.
