## 2. 항목별 검증 결과

### 2.1 수집 데이터 품질이 매매에 미치는 영향 (rev.3 신규)

단타 매매에서 데이터 품질은 생사를 가른다:

1. **premarket 건수 부족** (1,500건 미만): 전 종목 대비 40% 미만이면 스크리닝 결과 왜곡. 거래량 상위 종목이 누락되면 기회 상실보다 **잘못된 종목 선정이 더 위험**
2. **close_price null**: 전일 종가 없으면 변동률(change_rate) 계산 불가 -> 스크리닝 팩터 전체 무효. `passes_primary_filter`에서 `change_rate`가 핵심 조건
3. **volume null**: 거래량 비율(volume_ratio >= 2.0)이 1차 필터 첫 번째 조건. volume이 null이면 필터 자체가 무의미
4. **data_date 오래됨**: 5일 전 데이터로 거래량 비율 계산하면 완전히 다른 시장 상황. 모멘텀 팩터도 왜곡
5. **ETF 시세 0건**: ETF 레버리지/인버스 매매 자체가 불가능

### 2.2 primary_screen 0건 — 매매 안 하는 것이 정답 (rev.3 신규)

시장이 극도로 횡보하거나 변동성이 낮으면 필터 통과 종목이 0건일 수 있다:
- `change_rate_min: 1.0` (1% 이상 변동 필요) + `volume_ratio: 2.0` (전일 대비 200%) 
- 시장 전체가 조용하면 이 조건을 통과하는 종목이 없음
- 0건 = **매매하지 마라는 시장 시그널**
- failed 처리하면 쓸데없는 장애 알림 발생
- warning + "오늘은 매매 대상 없음" 텔레그램 알림이 적절

### 2.3 data_date 유효 범위 T-2 (rev.3 신규)

- T-1: 정상 (전일 데이터)
- T-2: 연휴/데이터 지연으로 허용 가능. 2일 전 데이터도 단기 추세 파악에 유효
- T-3 이상: 시장 상황이 이미 변했을 가능성 높음. **거래량 패턴이 3일이면 완전히 바뀐다**

### 2.4 ETN 시세 공백 (rev.3 신규)

현재 매매 전략이 ETF 레버리지/인버스 중심이므로 ETN 시세 없어도 당장은 문제없다:
- ETN은 일반적으로 ETF보다 유동성이 낮아 단타에 부적합
- ETN 매매 대상 추가는 Phase 5 범위
- 하지만 원자재/금리 ETN은 특정 장세에서 유용할 수 있으므로 기록

### 2.5 ETF 수집률 50% 하한 (rev.3 신규)

**동의한다. 실제로는 90%+ 이어야 정상이다.**

inquiry_client가 LIVE 도메인을 사용하므로 정상 상황에서 실패율은 매우 낮을 것. 50%는 "이건 확실히 문제"라는 최소 기준. 1주일 운영 데이터를 보고 80%로 상향 검토.

### 2.6 조회 데이터 정확성 (rev.2 유지)

실전 도메인 조회 -> 실제 시장 데이터 수집 보장. "실전 데이터로 분석하고, 모의 환경에서 매매한다" -- 이것이 모의거래의 올바른 사용법.

## 3. 파라미터 조정 권고 (rev.3)

| 항목 | 기존 확정값 | 권고 수정값 (rev.3) | 근거 |

| market_data 신선도 | T-2 거래일 이내 | 유지 (Sprint 2) | 도메인 분리와 무관하게 필요 |

## 4. 리스크 및 대안

- **공공데이터포털 데이터 지연이 심해지면**: data_go_kr이 T-3 이전 데이터만 제공하는 상황 가능. KIS REST로 당일 주식 시세 보완하는 방안 검토 (Phase 5 범위)
- **장 시작 전 데이터 갱신 타이밍**: 08:00 수집 -> 08:10 스크리닝 -> 09:00 장 시작. 유효성 검증 추가로 수집 시간이 약간 늘어나도 충분한 여유
- **ETF 수집률 변동**: 장전(08:15)에 ETF 시세 조회 시 전일 종가 기준으로 반환됨. 장 시작 전이므로 당일 시초가는 아직 없음 -- 정상 동작
- **임계값 운영 보정**: 1주일 운영 후 실제 수집 건수 분포를 확인하고 임계값 조정. 현재 1,500은 보수적 설정

## 최종 판단

**rev.3 수정안 강력 승인**. 유효성 검증은 매매 안전의 필수 요소다. 잘못된 데이터로 매매하는 것이 매매를 안 하는 것보다 위험하다.
