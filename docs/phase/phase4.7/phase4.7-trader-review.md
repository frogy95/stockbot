## 2. 항목별 검증 결과

### 2.1 실전 매매 관점에서의 1차 스크리닝 역할

1차 스크리닝(장전)의 목적:
- **"오늘 관심 가질 종목 목록"** 생성
- 전일 거래량 급증, 변동성 확대, 모멘텀 상승 종목 포착
- 이 목록을 기반으로 WS 실시간 구독 → 2차 스크리닝 대상 확정

체결강도/호가잔량은 **장이 열려야 생기는 데이터**:
- 체결강도: 매수체결량 / 매도체결량 * 100. 장전엔 체결 자체가 없음
- 호가잔량: 매수/매도 호가 잔량 비율. 프리마켓 호가는 의미 제한적
- 이 두 팩터를 1차에 넣은 것 자체가 설계 오류

### 2.2 3팩터의 실전 유효성

| 팩터 | 장전 유효성 | 실전 의미 |
|------|-----------|---------|
| volume_factor (거래량 비율) | ✅ 높음 | 전일 거래량 급증은 다음날 변동성/수급 변화의 강력한 선행 지표 |
| volatility_factor (ATR) | ✅ 높음 | 최근 변동성이 큰 종목 = 단타 수익 기회 |
| momentum_factor (3일 수익률) | ✅ 중간 | 단기 모멘텀은 유효하나 과열 경계 필요. change_rate 필터와 중복 가능성 |

### 2.3 임계값에 대한 의견

**1차 스크리닝에서 너무 많이 걸러서는 안 된다**:
- 1차의 역할은 "대략적 후보 선정"
- 진짜 걸러야 할 곳은 2차 (실시간 데이터 기반)
- max_candidates=30이 실질적 상한이므로, is_passed 임계값은 넉넉하게

**권고**: 초기 pass_threshold = 50.0 ~ 60.0 사이. 리스크 관리자와 타협하여 60.0 수용.

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| 1차 pass_threshold | 80.0 | **60.0** (최리스크 합의) | 상위 40% 통과. max_candidates가 최종 제한 |
| 2차 pass_threshold | 80.0 | **75.0** | 5팩터 실시간 기반. 초기 넉넉하게 운영 후 보정 |
| 1차 팩터 가중치 비율 | 균등 | **volume 0.4 / volatility 0.3 / momentum 0.3** 검토 | 거래량이 단타에서 가장 중요한 팩터. 단, 퀀트와 논의 필요 |

### 3.1 가중치 비대칭에 대해

거래량이 모든 것의 기반이라는 원칙에서:
- volume_factor에 더 높은 가중치를 줄 근거가 있음
- 그러나 퀀트 전문가의 "단순한 전략이 살아남는다" 원칙도 일리 있음
- **합의안**: 초기에는 균등(1/3)으로 시작, 2주 운영 데이터 후 IC 기반 조정

## 4. 리스크 및 대안

| 리스크 | 심각도 | 대응 |
|--------|--------|------|
| 장전 데이터 부실 (공공데이터포털 T+1 지연) | High | Phase 4.6에서 날짜 폴백 구현 완료. 데이터 없으면 스크리닝 자체 스킵 |
