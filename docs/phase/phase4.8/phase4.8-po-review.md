## 4. 리스크 및 대안

- **리스크**: KIS 모의거래 Rate Limit(초당 1건)으로 2,500종목 수집 시 ~42분 소요 → 장 시작 전 완료 불가
- **대안**: 실전 API 사용 시 초당 20건 → ~2분. 또는 1차 스크리닝 후보만 KIS로 수집(최대 500종목)
- **권고**: 포털 실패 시 **전 종목이 아닌 주요 종목(시총 상위 + 활성 종목)만** KIS로 수집하여 Rate Limit 내 처리
