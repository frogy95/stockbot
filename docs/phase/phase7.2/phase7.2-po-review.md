## 2. 항목별 검증 결과

### Sprint 1: 장중 OHLC 데이터 파싱 수정
- **판정: 즉시 수행** — H0STCNT0에 시가/고가/저가가 이미 포함되어 있는데 파싱하지 않은 것은 단순한 누락. 수정 범위도 작음 (파서 3필드 추가 + Redis 캐싱 + snapshot 조립 수정).
- 이 수정 없이는 Phase 7.0 Sprint 3 "E2E 검증"의 "신호 생성 1건+" 조건 충족 불가.

### Sprint 2: 진입 조건 다층화
- **판정: MVP 완성에 필수** — 2026-04-17 LIVE 모니터링에서 2차 스크리닝 통과 종목이 매 30초 나오지만 매매 신호 0건인 상태는 "동작하는 소프트웨어"가 아님.
- 다만 **전략 변경은 Sprint 1 데이터 수정 후 관찰 기간을 두고** 진행해야 함.
- 전략 옵션은 전문가 합의 후 결정. 한 스프린트에 하나의 핵심 목표 원칙 준수.

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |

## 4. 리스크 및 대안

- **리스크**: Sprint 1 OHLC 수정만으로 신호가 발생할 수 있음 → Sprint 2가 불필요해질 가능성
  - **대안**: Sprint 1 배포 후 2거래일 관찰. 신호 발생 빈도/품질에 따라 Sprint 2 범위 조정
- **리스크**: 진입 조건 완화 시 신호 남발 → 무분별한 매매
  - **대안**: confidence 임계값 유지(0.6)하되, 낮은 기준점에서의 confidence 가중치를 보수적으로 설정
