## 2. 항목별 검증 결과

### 실전 관점에서의 현재 전략 평가
- **전일 고가 돌파는 가장 보수적인 진입 기준 중 하나**. 모멘텀 전략으로서는 맞지만, 한국 시장 특성상 전일 고가 돌파 종목은 이미 +3~5% 이상 상승한 상태가 많아 진입 타이밍이 늦음.
- 실전에서 단타 트레이더들이 주로 사용하는 진입 기준:
  1. **전일 종가 돌파** — 가장 보편적. "어제보다 비싸다 = 매수세 존재" 확인
  2. **당일 시가 돌파** — 장 시작 후 눌림 후 시가 재돌파 = 당일 방향 확인
  3. **전일 고가 돌파** — 강한 모멘텀 확인. 하지만 진입가가 높아 손절 폭 제한
  4. **당일 고가 갱신** — 추격매수. 성공 시 수익 크지만 실패 시 고점 물림

### 다층 진입 권고
- **A안 (전일 종가 돌파 + 전일 고가 돌파 2단계)** 전원 합의:
  - 1단계: prev_close 돌파 + 거래량/체결강도 충족 → 탐색적 진입 (낮은 confidence)
  - 2단계: prev_high 돌파 → 확신 진입 (높은 confidence)
  - 이미 구현된 confidence 프레임워크와 자연스럽게 통합됨

- **갭 돌파(3%+) 분기 수정**:
  - 현재 `breakout_ref = snapshot.high` 로직은 갭 상승 종목의 당일 고가 돌파를 의미하는데, 이는 추격매수와 같음.
  - **갭 3%+ 시 시가(open_price)를 기준으로 변경** 권고: 갭 상승 후 시가 위에서 거래 유지 = 갭 지지 확인 = 상승 지속 가능성 높음

### 시간대별 고려사항
- 09:00~09:30은 이미 관망 시간(신호 차단). 이 규칙 유지.
- 09:30~10:30 골든타임: prev_close 돌파 진입 가장 효과적. 거래량 집중 시간.
- 10:30~14:00: 횡보 구간에서 prev_close 돌파는 false positive 높음 → 거래량 임계값 상향 권고
- 14:00~14:30: 마감 직전 돌파는 당일 청산 시간(14:50) 부족 → 진입 차단 유지
