> **검토 대상**: 2차 스크리닝 풀 하한 폴백 + 전략 게이트 재튜닝 + 관측성 강화의 통계적 타당성
> **검토일**: 2026-04-22
> **검토 방식 제약**: phase-planner가 서브에이전트 스폰 도구 부재로 페르소나 기반으로 직접 작성. 페르소나 원칙 — "데이터가 말하게 하라, 단순한 전략이 살아남는다, 과적합 경계" — 엄격 적용.

## 1. 요약

**판정**: ✅ 통과 (조건부) — 관측성 기반 의사결정 체계로 귀결시키는 것이 정답

본 브리지 Phase의 본질은 **"통계적으로 관측하지 않고 있었던 두 개의 분포를 관측 가능하게 만드는 것"**이다:
1. 2차 스크리닝 total_score 분포 — 75점 임계값이 적절한지 확인하려면 실제 분포가 어디에 있는지 먼저 봐야 한다
2. 전략 stage 탈락 분포 — 어느 stage가 실질 병목인지 데이터로 확인

이게 먼저 되면 이후 파라미터 조정은 **감이 아닌 분포 기반**으로 할 수 있다. 이 순서가 아니면 모든 조정이 과적합 리스크를 안는다.

풀 하한 폴백은 "상대 백분위 + 절대 하한 혼합"의 약식이므로 Phase 10.1 하이브리드와 구조적으로 같은 방향. Phase 10.1 고도화 시 자연스럽게 흡수 가능.

## 2. 항목별 검증 결과

### (A-1) 2차 스크리닝 모집단 하한 폴백

**판정**: ✅ 통계적 타당

**분석**:
- 현재 `pass_threshold=75.0` (realtime_screener.py:42)은 5팩터 가중합 100점 만점 기준
- 1종목만 통과 = 분포 중앙값이 75 이하이거나, 분포가 지나치게 평평함
- 모집단 N=1은 **어떠한 통계적 신뢰구간도 생성 불가능**한 상태. 이 자체가 설계 오류

**권고**:
- 폴백 조건: `통과 종목 수 < 3` → 상위 점수 순 보강하여 최소 3종목 확보
- 폴백으로 보강된 종목에 `is_fallback=True` 플래그 + `raw_score`, `percentile_rank` 메타데이터 기록
- **통계적 목적**: 추후 실측 데이터로 `pass_threshold` 재교정 시 **하한 이하 종목의 실제 신호 품질**을 비교할 수 있음 (자연 A/B)

### (A-2) min_volume_floor 재튜닝

**판정**: ⚠️ 수정안 권고 — 시간 슬라이딩보다 **돌파 강도 연동**이 통계적으로 우월

**분석**:
- 시간 슬라이딩(0.2→0.5)은 **시간 변수 1개에 조건부**한 파라미터 — 추가 자유도 1개
- 돌파 강도 연동은 **이미 모델이 가진 변수(gap_rate, breakout_ratio)**에 조건부 — 자유도 증가 없음
- 단순한 전략이 살아남는다 — 파라미터를 늘리지 않고 기존 변수로 조정하는 방향이 과적합 리스크 낮음

**권고 수정안** (최리스크 A-2 수정안과 일치):
```
floor(snapshot) = 0.4 if gap_rate >= 0.05 OR (tier=="prev_high" AND breakout_strength >= 0.03)
                = 0.6 if tier == "prev_close"
                = 0.5 otherwise
```
- 이 형태는 Phase 6.1 시간가중 보정과도 자연스럽게 결합됨 (시간가중 보정된 거래량에 floor 적용)

### (A-3) prev_close_time_guard 연장

**판정**: ❌ 거부 (통계적 근거 부재)

**분석**:
- 13:00 → 14:00 연장은 **추가 1시간 동안 prev_close tier 신호 발생 가능성 증가**
- 그러나 현재까지 **prev_close tier의 시간대별 기대 승률 데이터가 없음** — 13:00 이후 성과 비교 불가능
- 데이터 없이 연장하는 것은 과적합(=감적합) — 박퀀트 원칙 위반

**대안**:
- Phase 8.5 관측성 대시보드에 **"prev_close tier 신호가 13:00 이후 발생했다면 생성되었을 가상 신호 카운트"**를 로그로 남김 (가상 신호, 실제 실행 안 함)
- 1개월 관측 후 가상 신호 가상 성과 통계 수집 → Phase 10.1 근거 데이터로 활용

### (A-4) 관측성 강화

**판정**: ✅ 전면 승인 — 통계적 의사결정의 필수 인프라

**구체 권고**:
1. **stage 분포 메트릭 (시계열)**:
   - 1분 bucket, stage별 reject 카운트 + pass 카운트
   - 히스토그램 유형: `reject_count{stage}` 카운터 (Prometheus 스타일)
2. **secondary total_score 분포 (히스토그램)**:
   - 10점 bucket (0~100) × 10개 + `>=75` 별도 카운트
   - 일별 집계 + 7일 이동 분포 비교
3. **stage별 시간대 분포 (heatmap)**:
   - x축 = 시간(09:00~15:00, 10분 bucket), y축 = stage
   - 셀 값 = reject 카운트
4. **폴백 발동 통계**:
   - 일별 폴백 발동 횟수, 폴백 종목 평균 score, 폴백 종목 신호 발생 여부

## 3. Sprint 3 DoD 통계적 재정의

### 원안의 통계적 약점

"신호 발생 3거래일 연속"은 **시계열 조건**인데, 현 모집단 N=1 상태에서 **연속 사건의 확률**은 0에 수렴. 게다가 "다층 진입 분기 각 1회"는 gap_open 분기가 발동하려면 `gap_rate >= 3%` 필요 — 이건 시장 이벤트 의존이라 의도적으로 달성 불가능한 조건.

### 박퀀트 권고 DoD

- **5거래일 표본에서**:
  - 일평균 신호 발생 수 ≥ 1 (기대값 관점)
  - **신호 0건 거래일 비율 ≤ 40%** (즉 0건 일수 ≤ 2/5)
  - 2차 스크리닝 풀 크기 평균 ≥ 3 종목
  - stage 탈락 분포에서 **단일 stage 100% 집중 사례 없음** (전 stage 대비 어느 하나도 >90%이면 게이트 설계 재검토)
- **의도적 tier 다양성**:
  - prev_high tier 발동 1회+ (시장 조건 충족 시)
  - prev_close tier 발동 1회+ (13:00 이전 필수)
  - gap_open tier는 **시장 의존 조건으로 권장 조건, 필수 아님**
- **표본 < 5거래일 시**: 통계적 판정 금지, 관찰 연장

이 DoD는 **과적합 방지**와 **실현 가능성** 둘 다 확보한다.

## 4. 4개 질문 답변

### Q1: 풀 확장 vs 게이트 완화, 무엇이 먼저?

**답**: **풀 확장이 절대 우선**

**근거 (통계적)**:
- 풀 크기 N에 대한 신호 발생 확률을 대략 `P_signal = 1 - (1 - p)^N` 형태로 모델링
- `p` = 개별 종목이 게이트 통과할 확률 (현 약 5~10% 추정, 오늘 관측상 0%)
- N=1, p=0.05: `P_signal = 5%` (일평균 5%)
- N=5, p=0.05: `P_signal ≈ 23%`
- N=1, p=0.10: `P_signal = 10%`
- N=5, p=0.03 (게이트 더 엄격): `P_signal ≈ 14%`

→ **N을 5배로 늘리는 것이 p를 2배로 늘리는 것보다 신호 생성에 압도적으로 효과적**
→ 게이트는 품질 보호, 풀은 기대값 보호. 기대값이 0인 상태에서 품질 논의는 무의미

### Q2: min_volume_floor 시간 슬라이딩 형태?

**답**: **시간 슬라이딩 거부, 돌파 강도 연동 동적 floor 권고** (A-2 수정안)

**근거**: 시간 변수 추가는 자유도 1 추가 = 과적합 1단계 증가. 기존 변수(gap_rate, tier, breakout_strength)로 조건 분기가 더 parsimonious하다.

### Q3: prev_close_time_guard 13:00 → 14:00 안전한가?

**답**: **데이터 없음, 거부**

**근거**: 13:00 이후 prev_close tier 성과에 대한 관측 데이터 0건. 데이터 없이 파라미터 완화는 감적합. 대신 가상 신호 로깅으로 1개월 후 데이터 기반 재결정.

### Q4 (추가): 풀 하한 폴백 MVP를 Phase 8.5에 흡수해도 Phase 10.1 하이브리드와 충돌하지 않는가?

**답**: **충돌 없음, 오히려 자연스러운 증분**

**근거**: Phase 10.1의 하이브리드 스크리닝(상대 백분위 70% + 절대 점수 30%)은 **자기 자신의 상위 특수 케이스가 풀 하한 폴백**이다 (N<3일 때 상대 백분위 100%로 간주하고 상위 3종목 선택). Phase 10.1에서는 이걸 "N과 무관하게 항상 작동하는 2-stage 스코어"로 고도화하는 것. Phase 8.5 MVP는 그 하위 집합.

## 7. 리스크 및 대안
