## 1. 04월 4째주 시장 환경 평가

**단타 친화도 점수: 2.5 / 10 (매우 불리)**

이번 주는 한 마디로 **"단타 트레이더가 PC를 끄고 쉬는 게 정답이었던 주"** 다. 04-23 목요일은 옵션만기 직후로 외인 선물 포지션 정리 후유증이 코스피·코스닥 양쪽에 깔리면서 거래량 자체가 평소 대비 70% 수준으로 가라앉았다. 04-24 금요일은 주말 리스크 회피로 대형주는 박스권 상단에서 미끄러졌고, 그나마 단 1건 잡힌 prev_high 신호도 갭 없이 옆으로 기어가다 후반에 살짝 뚫은 종목으로 추정된다 — 이 한 건이 시장 전체의 "유일한 진짜 돌파"에 가깝다.

문제는 04-27, 04-28이다. 월·화 연속으로 신호 0건인데, 폴백이 81회·271회로 폭발한 건 **"풀 하한 폴백은 발동하지만, 그 폴백 종목들조차 tier 게이트(gap_open / prev_high / prev_close) 어느 하나도 못 뚫는다"** 는 뜻이다. 이건 시스템이 풀을 만들어도 시장에 돌파 자체가 없다는 신호다. 화요일 271회는 수치만 보면 데이터 폭증인데, 실제로는 같은 4종목(042700 외)을 30분~1시간 주기로 재평가한 누적치일 가능성이 크다 — 즉 폴백 종목이 종일 옆으로 기었다는 뜻.

실전 트레이더 입장에서 이번 주는 **"시장 탓 70%, 시스템 탓 30%"** 다. 시장 탓은 명백하다 — 갭상승 종목 부재, 거래량 침체, 박스권. 다만 시스템 탓 30%는 **"prev_high tier 1건이 발생한 04-24의 그 종목 외에, 04-23 목요일에도 분명히 장 후반 갭 메우기 후 재돌파한 중소형주가 한두 종목은 있었을 텐데 0건"** 이라는 점이다. 이건 시스템이 잡아야 할 진짜 단타 패턴(거래량 급증·VI 발동·테마 강세)을 구조적으로 못 본다는 방증이다. 분기 D 자동 롤백은 **시장 환경 + 패턴 커버리지 한계가 동시에 노출된 결과**로 봐야 한다.

## 2. 시스템이 놓치는 단타 패턴

### 패턴 1: 거래량 급증 + 호가창 매수 잔량 압도 (실전 1순위)

실전에서 단타가 가장 사랑하는 패턴이다. 전일 종가 ±1% 부근에서 횡보하다가 **5분봉 거래량이 직전 5개 봉 평균 대비 5배 이상 터지면서 매수 호가 1~5호가 잔량이 매도 잔량의 2배 이상**으로 깨지는 순간 — 이게 진짜 돌파의 90%를 결정한다. 현재 시스템은 prev_high·prev_close 같은 **가격 기준 돌파**만 본다. 그래서 "거래량은 터졌는데 아직 전일 고가는 안 뚫은" 직전 5분의 진입 골든타임을 통째로 놓친다. 신호화는 단순하다 — `volume_5m_ratio >= 5.0 AND bid_ask_imbalance >= 2.0` 두 조건이 충족된 시점을 새 tier `volume_surge`로 정의하면 된다. 04-28 화요일 폴백 종목들 중 분명 장중 한 번씩은 이런 순간이 있었을 것이다.

### 패턴 2: VI(변동성 완화장치) 발동 직후 재개 진입

코스닥 단타의 보석. 정적 VI는 ±10%, 동적 VI는 직전 체결가 ±2~3% 변동 시 2분간 단일가로 묶이고, 재개 시점에 **세력의 손이 한 번 더 들어가면서 갭 띄우기**가 자주 나온다. VI 발동 자체가 거래량·변동성·관심도 3박자 충족의 객관적 지표다. 현재 시스템은 VI 이벤트를 전혀 보지 않는다 — KIS API의 `H0STCNT0` 실시간 시세 + VI 발동 종목 조회 API(`/uapi/domestic-stock/v1/quotations/inquire-vi-status`)를 polling하면 신호화 가능. tier `vi_resume`으로 추가하고 발동 후 첫 1분 거래량이 직전 평균 대비 3배 이상일 때만 진입하면 가짜 신호 대부분 걸러진다.

### 패턴 3: 동시호가 갭상승 + 시초가 매물 흡수

09:00 동시호가에서 전일 종가 대비 +3~5% 갭상승으로 시작했는데, **09:00~09:10 사이 시초가 매물(차익실현)을 거래량으로 흡수하면서 시초가 부근을 지지선으로 만드는 종목** — 이게 갭 단타의 정석이다. 현재 시스템은 09:30 이전 진입을 막고 있고(이건 안전성 측면에서 옳다), 그러다 보니 09:30에 진입할 때는 이미 1차 시세가 끝나 있다. 신호화 방법은 직접 진입 신호가 아니라 **09:00~09:30 watchlist 자동 등록**이다 — 갭 +3% 이상 시작 + 09:10 시점 거래량이 전일 1시간 평균 이상인 종목을 09:30 진입 우선순위 큐에 자동 추가하면, 30분 후 본매매 시점에 즉시 반응 가능.

### 패턴 4: 테마주 동조 강세 (섹터 모멘텀)

단타의 절반은 테마다. 2차전지·AI·바이오 같은 테마가 그날 강세면 같은 섹터 5~10종목이 동시에 +3~5% 출발한다. 현재 시스템은 종목별 독립 평가만 한다 — 옆에 있는 동종 테마가 터지고 있다는 정보를 전혀 반영 못 한다. 신호화는 두 단계: (1) 섹터 분류 메타데이터 확보 (KRX 업종 코드 또는 테마 분류), (2) 같은 섹터 N종목 중 K종목 이상이 +2% 이상이면 그 섹터 전체에 `theme_momentum` 가중치 +20점 부여. 04-23~28 같은 침체장에서도 **하루는 분명히 한 테마가 강세**였을 것이다 — 그 테마 종목을 잡아야 했다.

### 패턴 5: 장 마감 30분 전 종가 베팅 돌파

14:30~15:00 구간에 **외인·기관 종가 매수**가 들어오면서 그날 박스 상단을 뚫는 패턴. 다음 날 갭 시작을 노리는 자금이다. 현재 시스템의 prev_close_time_guard 13:00은 이 구간을 막지 않으니 진입 가능 시간대지만, prev_close tier만으로는 "오후 3시에 막판에 뚫은 게 진짜 매집인지 판단" 불가. 신호화는 **14:30+ 한정 신규 tier `late_breakout`**: 14:30 이후 + 외인/기관 순매수 +α + 거래량 급증 동시 충족. 단 청산 시간이 짧으니 익일 시초가 매도를 강제하는 종가 베팅 모드와 페어링 필요.

## 3. Phase 10.1 단타 친화적 개선 우선순위

### 1순위 — 거래량 급증 + 호가창 압도 tier 신설 (`volume_surge`)

가장 ROI 높은 개선이다. 위 패턴 1을 신호화하는 일이며, 04-28 화요일처럼 폴백은 발동했지만 가격 돌파가 없는 날에 **거래량이라는 진짜 단타 신호**를 잡아낸다. 구현 비용은 중간 — KIS WebSocket 실시간 체결가/호가 스트림을 5분봉으로 집계하는 인프라가 필요하지만 Phase 9 Sprint 0에서 5분봉 수집 인프라를 깔기로 한 ROADMAP과 정확히 맞물린다. 게이트는 보수적으로: `volume_5m_ratio >= 5.0`, `bid_ask_imbalance >= 2.0`, 09:30~14:00 한정. 손절은 5분봉 저가 -1.5%로 타이트하게. 이 하나만 추가해도 04-23~28 같은 박스권에서 신호 빈도가 1.5~3배로 늘 것으로 본다.

### 2순위 — 섹터/테마 모멘텀 가중치 (`theme_momentum_score`)

단타 실전 감각의 핵심이다. 현재 1차/2차 스크리닝이 종목 독립 평가인 점을 보완. 구현 비용은 낮음 — KRX 업종 분류 API 또는 정적 섹터 매핑 테이블 + 동일 섹터 K/N 강세 비율 계산만 하면 된다. 효과는 두 가지: (1) 약한 신호여도 섹터 동조 시 통과, (2) 단독 강세는 가중치 안 줘서 펌프&덤프 종목 자연 필터. 게이트 자체에 박는 것보다 **2차 스크리닝 total_score에 +10~20점 부여하는 형태**가 안전하다 — 게이트가 아니라 우선순위 부스트로 도입하면 회귀 위험 최소.

### 3순위 — VI 재개 tier (`vi_resume`)

코스닥 중소형주 단타의 보석이지만 변동성 리스크가 큰 만큼 3순위. 1·2순위 정착 후 도입 권고. 구현 비용은 낮음 — KIS VI 발동 종목 조회 API polling(30초 주기)으로 충분. 핵심은 **세이프티**: 발동 종목 자체가 이미 변동성 임계치를 넘은 종목이라 시스템 자동 진입은 위험. 첫 도입 시엔 **반자동 모드 한정**(텔레그램 알림 → 사용자 수동 승인)로 시작해서 1개월 데이터 축적 후 자동 진입 조건 확정. position_size도 일반의 50%, 손절 -1.5%, 익절 +3% 강제. 이 tier는 "잡으면 큰 거 한 방"이라 실전 수익 기여도는 1·2순위보다 클 가능성도 있다.

## 결론 한 줄

이번 주 신호 1건은 시장 탓 70% + 시스템의 가격 기준 단일 시각 한계 30%가 동시에 노출된 결과이며, Phase 10.1은 **거래량/호가창 기반 `volume_surge` tier 신설을 1순위**로 단타 실전 패턴 커버리지를 확장해야 한다.
