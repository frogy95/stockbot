# Phase 8.5 분기 D 재리뷰 — PO 관점

작성일: 2026-04-28
배경: v2.6.1 배포 후 자동 롤백 발동 (분기 D 확정 — 04-27·04-28 연속 2거래일 신호 0건, `auto_rollback_2d_zero_signals`)

---

## 1. 자동 롤백 원인 분석 (PO 관점)

분기 D는 "Phase 8.5 폴백 로직이 동작하지 않았다"가 아니라 **"동작했음에도 신호가 안 났다"** 에 가깝다. M-F1이 4거래일 모두 발동(605회 누적)했고, M-F2(폴백 신호율)는 측정 불가 상태로 끝났다. 즉 폴백은 정상 작동했지만 **폴백으로 끌어올린 종목들도 전략 게이트를 통과하지 못했다**.

PO 관점의 1차 책임은 **시뮬 가정과 실거래 시장의 ATR/거래량 분포 괴리**에 있다. Phase 8.5 사전 PO 리뷰(2026-04-22) 시점에서 박퀀트 시뮬은 38.9% 2차 통과율을 근거로 풀 하한 폴백만으로 충분하다고 판단했지만, 실제 04월 4째주는 **저변동성·저거래량 장세**(M-S1 1건, tier 다양성 prev_high만 1종)였다. 이는 시뮬 데이터셋이 시간대 분포와 변동성 레짐을 충분히 커버하지 못했다는 **방법론적 누락**이다.

2차 책임은 **scope guard의 부작용**이다. 사전 리뷰에서 "min_volume_floor 시간대 슬라이딩 0.3"을 SHOULD로 권고하면서도 "회귀 원인 식별 불가" 우려로 A-1/A-3와 동시 배포를 막았는데, 결과적으로 폴백 단독 효과는 입증됐으나(M-F1 발동) 다음 게이트에서 모두 차단되어 **신호 산출까지 도달하지 못한 채 롤백 트리거가 먼저 닿았다**. 즉 "보수적 단계 배포"의 본 의도(회귀 통제)는 달성됐지만, **자동 롤백 임계값(2일 연속 0건)이 단계 배포 시간축보다 짧았다**는 설계 미스매치가 드러났다.

요약: 폴백 로직 자체는 정상이며 분기 D는 **(a) 시장 레짐 가정 미스, (b) 게이트 다층 차단, (c) 자동 롤백 임계값과 단계 배포 일정의 불일치** 세 가지가 합쳐진 결과다.

## 3. Phase 10.1 착수 타이밍 권고

**권고: 1주 추가 관찰 후 Phase 8.5 Sprint 2.6(파라미터 미세조정 + M-F2 측정) 재배포. Phase 10.1 즉시 착수는 거부.**

근거:

1. **분기 D는 Phase 10.1 필요성을 입증하지 않는다.** 자동 롤백은 신호 0건이지 신호 품질 문제가 아니다. Phase 10.1(하이브리드 진입)은 신호가 충분히 나오는 환경에서 진입 정밀도를 높이는 작업이며, 신호 자체가 안 나오는 현 상태에서 착수는 **문제 정의가 어긋난다**.

2. **데이터 의존성 미해소.** Phase 10.1 하이브리드 검증은 충분한 신호 표본(주당 ≥10건)을 전제로 한다. 현재 1주 1건 페이스에서 Phase 10.1 착수 = 검증 데드락 재발생.

3. **Sprint 2.6 일정 추정**: 파라미터 조정 + M-F2 + 시뮬 재검증 = 1주 내. Phase 10.1 본 스펙(2~3주)보다 짧고 분기 D 원인을 직접 해소.

4. **시장 환경 변화 대기는 거부**: 사용자 지시 원칙(무의미한 대기 제거)과 충돌. 능동적 Sprint 2.6으로 대응.

조건부 트리거: Sprint 2.6 재배포 후에도 5거래일 M-S1 ≥5 미달 시 비로소 Phase 10.1 조기 착수 검토(시장 레짐이 시뮬과 구조적으로 다르다는 증거).
