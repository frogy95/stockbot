## 1. 요약

| 항목 | 판정 |
|------|------|

## 2. 항목별 검증 결과

### A. change_rate_min 완화
- **현행**: 1.0% (전일 +1% 이상만 통과)
- **문제**: 평시 장에서 대부분 종목이 -1%~+1% 범위 → 대량 탈락
- **판단**: MVP에서 "매매 불능"은 시스템 존재 의미 상실. Phase 5 volume_ratio 완화와 동일 논리 적용 필요.
- **권고**: change_rate_min을 -3.0으로 확대. 단, 리스크관리자/단타 전문가 의견 우선.

### B. change_rate_max 유지 여부
- **현행**: 7.0% (전일 +7% 초과 제외)
- **판단**: 상한가 근접 종목 제외는 합리적. 유지.

### C. 적응형 필터 확장
- **현행**: volume_ratio만 적응형 대상
- **판단**: change_rate도 적응형에 포함해야 "0건 통과" 근본 해소. 단, volume_ratio와 독립적으로 단계 완화.

### D. Sprint 범위
- **판단**: 단일 Sprint로 충분. 필터 조건 수정 + 적응형 확장 + 테스트. 코드 변경량 적음.

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| change_rate_min | 1.0 | -3.0 | 하락 후 반등 패턴 포함, 단타 기회 확대 |
| change_rate_max | 7.0 | 10.0 | 상한가(30%) 미만 유지하되 약간 확대 |
| 적응형 change_rate 포함 | 미포함 | 포함 | 0건 근본 해소 |

## 4. 리스크 및 대안
- **리스크**: 필터 완화 시 저품질 종목 유입 → 2차 스크리닝 부담 증가
- **대안**: change_rate 절대값 필터(|change_rate| >= 0.5) 도입 시 횡보 종목만 제외 가능
- **우선순위**: Phase 5 Sprint 3 전에 반드시 해결 (매매 불능 상태 지속 불가)
