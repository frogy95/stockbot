# Phase 5.1 리스크관리 검토 — 최리스크

> 검토일: 2026-04-08

## 1. 요약

| 항목 | 판정 |
|------|------|
| change_rate_min 완화 (-3.0) | ⚠️ 주의 — 허용하되 하락 종목 안전장치 필수 |
| change_rate_max 확대 (10.0) | ❌ 재검토 — 7.0 유지 권고. 고변동 종목 리스크 과대 |
| 적응형 change_rate 포함 | ✅ 통과 — 단, 최저 하한선 설정 필수 |
| 음수 등락률 종목 자동매매 | ❌ 재검토 — 하락 종목 완전 자동 매매 금지 |

## 2. 항목별 검증 결과

### A. change_rate_min 완화
- **리스크 분석**: 전일 하락 종목(-3%~0%)은 추가 하락 가능성 존재. 단, 0건 통과 = 매매 불능이 더 큰 리스크.
- **안전장치**: 하락 종목(change_rate < 0)은 반드시 `auto_trade_blocked: true` 플래그 설정. 반자동만 허용.
- **권고**: change_rate_min = **-3.0** 허용. 단, -3% 이하는 급락 가능성으로 제외.

### B. change_rate_max 확대
- **리스크 분석**: 전일 +7% 초과 종목은 과열 구간. +10%는 다음날 급락 리스크 높음.
- **판단**: **7.0 유지**. 상한 확대는 리스크 대비 기대 수익 불리.
- **근거**: 전일 +7% 초과 종목의 익일 평균 수익률은 통계적으로 음수 (과열 후 조정).

### C. 적응형 필터 change_rate 포함
- **허용 조건**: 적응형 완화 시 change_rate_min 최저 하한 = **-5.0**. 이 이하로 완화 금지.
- **완화 단계 권고**: [원래값(-3.0), -5.0] — 2단계만.
- **근거**: -5% 이하 종목은 구조적 악재(상장폐지, 대규모 유상증자 등) 가능성.

### D. 하락 종목 리스크 관리
- **필수 안전장치**:
  1. change_rate < 0 종목: `auto_trade_blocked: true`
  2. change_rate < -2% 종목: 포지션 사이징 50% 제한
  3. 적응형으로 통과한 종목: 알림에 "완화됨" 표시 (Phase 5 기존 로직 재활용)

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| change_rate_min | 1.0 | **-3.0** | 0건 방지, 단 하락 종목 안전장치 전제 |
| change_rate_max | 7.0 | **7.0 유지** | 과열 종목 제외는 리스크 관리 핵심 |
| 적응형 change_rate 하한 | - | **-5.0** | 구조적 악재 종목 절대 차단 |
| 하락 종목 자동매매 | - | **금지** | 미검증 하락 패턴 자동 주문 불가 |
| 하락 종목(-2% 이하) 사이징 | - | **정상의 50%** | 추가 하락 리스크 완화 |

## 4. 리스크 및 대안
- **최악 시나리오**: 전일 -3% 종목이 추가 -5% 하락 → 건당 최대 손실 확대
- **대응**: 기존 비상정지(-4%) + 포지션 사이징 50%로 리스크 제한
- **모니터링**: change_rate < 0 통과 종목의 익일 수익률 추적 필요 (Phase 6 백테스팅)
