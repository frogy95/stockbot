# Phase 5.1 퀀트 검토 — 박퀀트

> 검토일: 2026-04-08

## 1. 요약

| 항목 | 판정 |
|------|------|
| change_rate 필터 설계 오류 | ✅ 통과 — 명확한 설계 결함. 즉시 수정 필요 |

## 2. 항목별 검증 결과

### A. change_rate 필터의 통계적 분석
- **KOSPI/KOSDAQ 일평균 등락률 분포** (2024-2025 데이터 기준):
  - 평균: 약 0.0% (랜덤워크 가정)
  - 표준편차: 약 2.0~2.5%
  - +1% 이상 종목 비율: 약 25~30%
  - +1%~+7% 범위 종목 비율: 약 22~27%
- **결론**: change_rate_min=1.0은 전체 종목의 약 70~75%를 즉시 탈락시킨다. volume_ratio 필터와 결합하면 통과율이 극도로 낮아진다.

### B. change_rate_min 적정값
- **-3.0 vs -2.0 분석**:
  - -3.0: 전체 종목의 약 95% 포함 (1.5 sigma)
  - -2.0: 전체 종목의 약 85% 포함 (1.0 sigma)
  - 0.0: 전체 종목의 약 50% 포함
- **권고**: **-2.0** (1 sigma). -3.0은 너무 관대하여 저품질 종목 유입. 적응형으로 -3.0까지 확대 가능.
- **근거**: 1차 필터의 목적은 "명백한 비적격 종목 제거"이지 "최적 종목 선별"이 아님. 선별은 팩터 스코어링이 담당.

### C. 적응형 필터 change_rate 설계
- **권고 구조**:
  1. 기본: change_rate_min = -2.0
  2. 적응형 1단계: change_rate_min = -3.0
  3. 적응형 2단계: change_rate_min = -5.0 (최저 하한)
- **volume_ratio와 동시 완화**: 독립 단계로 운영. volume_ratio 완화 후에도 부족하면 change_rate 완화.

### D. 절대값 필터 (미래 개선)
- **|change_rate| >= 0.3%**: 완전 횡보(등락률 0 근처) 종목 제외
- **판단**: 현 Phase에서는 과도. Phase 6 백테스팅에서 효과 검증 후 도입.

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| change_rate_min | 1.0 | **-2.0** | 1 sigma 기준, 85% 종목 포함 |
| change_rate_max | 7.0 | **7.0 유지** | 최리스크 의견 동의. 3 sigma 수준 |
| 적응형 change_rate 단계 | - | **[-2.0, -3.0]** | volume_ratio 적응형과 독립 운영 |
| 적응형 최저 하한 | - | **-5.0** | 구조적 악재 종목 차단 |

## 4. 리스크 및 대안
- **과적합 경고**: change_rate 임계값은 시장 상황에 따라 최적값이 변동. 고정값보다 적응형이 본질적으로 우수.
- **검증 필요**: 수정 후 최소 10거래일 통과 종목 수 모니터링 → 평균 10~20개 목표
- **장기 개선**: 코스피/코스닥 지수 등락률 기반 동적 임계값 (Phase 6 이관 합의)
