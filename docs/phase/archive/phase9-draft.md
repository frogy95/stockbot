## 범위 및 목적

Phase 6.1의 선형 시간가중 보정(`adjusted_ratio = V / (V_prev * progress)`)을 **시간대별 실제 누적 비율 함수**로 교체한다. 한국 주식시장의 거래량은 장 시초와 종반에 집중되는 U자형 분포를 보이므로, 이 패턴을 반영한 비선형 보정이 장 중반부의 보수적 편향(~10~20%)을 해소한다.

### 핵심 아이디어 (박퀀트 권고)

```
현행 (선형): expected_volume(t) = V_prev * (t / T)
개선 (비선형): expected_volume(t) = V_prev * f(t)
  - f(t): 실제 관측된 시간대별 누적 거래량 비율 함수
  - f(t)는 U자형 — 09:00~10:00 급등, 10:00~14:00 완만, 14:00~15:30 재급등
```

- 선형 보정에서는 장 중반에 과소추정 → 보수적 편향
- U자형 보정은 실제 패턴을 반영 → 정밀도 향상
- 단, 파라미터 과적합 위험이 있으므로 충분한 데이터 필수
