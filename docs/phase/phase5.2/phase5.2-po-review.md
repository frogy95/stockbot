## 2. 항목별 검증 결과

### MVP 범위 적합성
- 이 문제는 **장중 전체 파이프라인(2차 스크리닝 + 매매 신호)을 마비**시키는 블로커. 즉시 수정 필요
- Phase 5 Sprint 3(성과 분석 대시보드)보다 우선순위 높음 — 실시간 데이터가 없으면 분석할 대상도 없음

### Sprint 분할
- 단일 Sprint 적절. 4개 파일 수정 + 테스트로 1일 내 완료 가능
- Phase 5 Sprint 3을 밀어내지 않기 위해 빠르게 처리

### 파라미터 의견
- paper 20종목: 1차 스크리닝 통과가 보통 15~30건. 20개면 상위 우선순위로 커버 가능하지만 빠듯
- **권고: paper 20 유지하되, 실전 전환 시 35 자동 적용 확인 필수**

## 4. 리스크 및 대안

- **리스크**: 모의 환경 제약이 실전에서는 다를 수 있음. 실전 전환 시 별도 검증 Sprint 필요

- **Phase 5 Sprint 3과의 관계**: 이 Phase 완료 후 Sprint 3 진행. 의존성 명시 필요
