## 2. 항목별 검증 결과

### 수학적 분석

1. **현재 코드의 문제는 "비교 대상의 단위 불일치"**:
   - `volume`(t): 시점 t까지의 누적 거래량 (0 ~ T 중 t 시점)
   - `prev_volume`: 전일 전체 거래량 (0 ~ T 전체)
   - `volume(t) / prev_volume < 2.0` 조건은 시간 t에 의존하는 변수와 시간 T에 의존하는 상수를 비교
   - 이것은 통계적으로 **비교 불가능한 량**을 비교하는 오류

2. **올바른 정규화**:
   - `V(t)` = 시점 t까지 누적 거래량
   - `V_prev(T)` = 전일 총 거래량
   - `progress(t) = t / T` (장 경과 비율)
   - **환산 거래량 비율** = `V(t) / (V_prev(T) * progress(t))`
   - 의미: "현재까지의 거래량 속도가 전일 평균 속도의 몇 배인가?"
   - 이것이 옵션 (c)의 공식이며, **유일하게 수학적으로 올바른 비교**

3. **선형 보정의 통계적 근거**:
   - 거래량의 일중 분포(intraday volume profile)는 U자형이 맞음
   - 하지만 U자형 보정은 시간대별 가중치 파라미터가 최소 6~12개 필요
   - 파라미터 수 증가 = 과적합 위험 증가 (원칙 #3 위반)
   - **선형 보정은 장 중반에 약 10~20% 보수적**(과소 추정). 이는 Type-I error(잘못된 진입)를 줄이는 방향이므로 리스크 관리에 유리
   - 결론: **선형 보정이 bias-variance 트레이드오프에서 최적**

4. **confidence 계산에 미치는 영향**:
   - 현재: `volume_score = min(volume_ratio / 5.0, 1.0)` (가중치 30%)
   - 보정 후 volume_ratio가 시간 독립적이 되므로, volume_score도 시간 독립적
   - 이는 confidence의 시간대별 일관성을 **대폭 개선**

### 옵션 (b) 거부 근거 (수학적)

임계값을 x로 낮추면:
- 통과 조건: `V(t) / V_prev(T) >= x`
- `V(t) = V_prev(T) * x` 시점에서 통과
- 전일과 같은 거래 속도면: `V(t) = V_prev(T) * progress(t)` -> `progress(t) = x`
- x=1.2이면 progress=1.2 -> **장 마감 후에야 통과** (불가능)
- x=0.5이면 progress=0.5 -> 장 중반(12:15)에 겨우 통과. 하지만 "전일의 절반" 거래량으로 매매한다는 것은 필터 무의미

결론: 임계값 조정으로는 **시간 비대칭 문제를 해결할 수 없음**. 차원이 다른 문제.

| 항목 | 원래값 | 권고값 | 근거 |

| progress 공식 | 없음 | **elapsed_minutes / 390** | 09:00~15:30 = 390분 |

| 절대 거래량 하한 | 없음 | **prev_volume * 0.3** | 최리스크 권고 동의. 극저 유동성 방지 |
| confidence volume_score | `volume_ratio / 5.0` | **adjusted_ratio / 5.0** | 보정된 비율 사용으로 시간 일관성 확보 |

## 4. 리스크 및 대안

### 과적합 경고
- 현재 변경은 파라미터 0개 추가 (기존 2.0 유지, progress는 현재 시각에서 결정론적 계산)
- min_progress (0.15)와 절대 하한 (0.3)만 추가 -> 총 2개 파라미터 추가
- **과적합 위험 매우 낮음** (원칙 #3 충족)

### 검증 방법 권고
- 구현 후 최소 5거래일간 로그 모니터링:
  - 시간대별 adjusted_ratio 분포 확인
  - 보정 전/후 통과율 비교
  - False positive(진입 후 즉시 손절) 비율 추적
- 백테스트는 현 시점 불필요 (장중 실시간 데이터 기반 전략이므로 과거 데이터로 정확한 재현 어려움)

### 장기 개선 (Phase 7.1+)
- 시간대별 거래량 프로파일 기반 비선형 보정 도입 가능
- 단, 최소 20거래일 데이터 축적 후 분석하여 결정
