## 2. 항목별 검증 결과

### 실전 트레이딩 관점

1. **거래량 조건의 본래 의도**: "전일 대비 2배 거래량"이 의미하는 것은 **"오늘 이 종목에 평소보다 2배 많은 관심/자금이 몰리고 있다"**는 것. 이걸 장 마감 기준으로만 판단하면, 오전에 이미 뜨거운 종목을 놓침.

2. **실전에서 트레이더가 보는 방식**: 프롭 데스크에서 실제로 사용하는 방법:
   - "이 시간까지 이 정도 거래량이면, 마감까지 전일 대비 몇 배 나올 것 같은가?"
   - 이것이 바로 **옵션 (c)의 시간가중 보정**과 동일한 직관.

3. **오늘 사례 분석 (062040 이수페타시스)**:
   - 13:17 KST 기준 vol=1,080,856 / pvol=968,175 = **1.117배**
   - 장 경과: 09:00~13:17 = 4시간 17분 / 6시간 30분 = **progress 0.66**
   - 시간보정: 1.117 / 0.66 = **1.69배** (예상 마감 거래량 비율)
   - 임계값 2.0 미달 -> 탈락. **이건 합리적**. 1.69배면 "평소보다 약간 많은 수준"이지 "이상 급증"은 아님.
   - 만약 같은 시간에 vol이 1,400,000이었다면: 1,400,000/968,175/0.66 = **2.19배** -> 통과. 이것이 올바른 동작.

4. **옵션 (b)가 왜 안 되는가**: 임계값을 1.5로 내리면, 위 사례에서 1.117 < 1.5 -> 여전히 탈락. 1.2로 내려야 겨우 통과하는데, 1.2는 거래량 증가를 거의 요구하지 않는 것이라 필터 의미 상실.

### 시간대별 실전 가이드

| 시간대 | progress | 특성 | 보정 적절성 |
|--------|----------|------|-----------|
| 09:00~09:30 | 0~0.08 | 시초가 급등락, 변동성 극대 | no_signal로 차단. 보정 불필요 |
| 09:30~10:30 | 0.08~0.23 | **골든타임**, 주도주 형성 | 보정 효과 최대. min_progress 0.15로 09:58부터 |
| 10:30~13:00 | 0.23~0.62 | 장 중반, 추세 확인 구간 | 보정 안정적 |
| 13:00~14:30 | 0.62~0.85 | 오후 매매, 보정 효과 감소 | 자연 누적에 근접 |
| 14:30~15:30 | 0.85~1.0 | 장 마감 전, 진입 차단 | is_entry_blocked() |

## 3. 파라미터 조정 권고

| 항목 | 원래값 | 권고값 | 근거 |
|------|--------|--------|------|
| volume_ratio 임계값 | 2.0 | **2.0 유지** | 시간보정으로 해결. "마감 기준 2배 예상" 의미를 정확히 보존 |
| min_progress | 없음 | **0.15** | 최리스크 의견 동의. 09:58 이전은 시초가 변동성으로 신뢰 불가 |
| 절대 거래량 하한 | 없음 | **prev_volume * 0.3** | 동의. 거래량 30% 미만이면 매매 자체가 위험(체결 어려움) |
| 선형 vs U자형 보정 | 없음 | **선형** | 동의. U자형은 파라미터 3~4개 추가 -> 과적합. 선형이 실전에서도 충분히 작동 |

## 4. 리스크 및 대안

### 핵심 리스크 인지
- **거래량 후반 집중 종목**: 일부 종목은 장 마감 전에 거래량이 폭발. 선형 보정은 이런 패턴을 감지 못함. 하지만 이런 종목은 **14:30 이후 진입 차단** 구간에 해당하므로 실질적 리스크 없음.

### 추가 권고 (Phase 7+ 과제)
- **거래량 가속도**: 단순 누적 비율보다 "최근 5분 거래량 / 직전 5분 거래량" 같은 가속도 지표가 더 강력. 하지만 현재 데이터 인프라(30초 주기 스크리닝)에서는 정밀도 부족. WS 틱데이터 기반 구현 시 Phase 7에서 추가 가능.
