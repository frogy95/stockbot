## 항목별 검증 결과

### 1. Phase 9와의 경계 명확화 ✅

- Phase 9 재검토에서 "단일 시점 통계는 백필/점진으로 완화 가능"
- Phase 10은 "함수 피팅이므로 완화 불가" — 완전 동의
- 이 경계 설정은 과적합 방지의 핵심 원칙

### 2. 함수 형태 선택 (Sprint 1) ⚠️

원안 "2차 다항식 또는 spline"이 모호.

**권고 명시**:
```
1순위: Cubic Spline (knot 5개: 09:00, 10:00, 11:30, 13:30, 14:30)
2순위: Piecewise Linear (슬롯 단위, 대안 C의 확장판)
3순위: Parametric (Admati-Pfleiderer U자형 함수)
```

- Cubic Spline이 데이터 적응성 최고, 해석도 직관적 (knot = 거래 패턴 전환점)
- 2차 다항식은 **U자형 강제**이므로 실제 분포 다를 때 왜곡

### 3. 교차 검증 절차 ⚠️

원안 "K-fold=5"만 명시. 실전에서는 **시계열 특성**을 고려한 분할 필요.

**권고 방법**:
```
TimeSeriesSplit (sklearn)
- n_splits = 5
- 각 fold에서 train_set은 과거 구간, test_set은 미래 구간만 사용
- 평균 R² + R² 표준편차 모두 보고
```

일반 K-fold는 미래 데이터로 과거를 예측하는 **look-ahead bias** 발생.

### 4. R² 기준 ⚠️

원안 "R² ≥ 0.90 / 0.95". 정프로 권고(0.85 at 2개월)와 조율.

**권고**:
| 축적 기간 | 대안 | 최소 R² | 비고 |
|---------|------|--------|------|
| 2개월 (40일) | 대안 C (슬롯 상수) | **N/A** (상수이므로 피팅이 아님) | 정프로 "의무 착수" 시점 |
| 3개월 (60일) | 대안 B + 자체 피팅 | **0.85** | Cubic Spline 최초 시도 |
| 6개월 (120일) | 완전 피팅 | **0.90** | 계절성 반영 |

R² 0.95는 과적합 징후. 0.90으로 하향.

### 5. A/B 비교 통계 설계 ⚠️

Sprint 2 A/B에 **통계적 유의성 검정** 필요.

**권고**:
- 선형/비선형 각 1개월 운영 후 일간 수익률 계산
- t-test 또는 Mann-Whitney U test로 유의성 검정
- p-value < 0.05 + 승자의 평균 수익률이 패자보다 실질적으로 우수할 때만 전면 전환

단순 "PnL이 높다" 기준은 우연일 수 있음.

### 6. Phase 9 Sprint 3 백테스트와의 연계 ✅

Phase 9 Sprint 3에서 구축한 백테스트 데이터셋을 Phase 10 A/B 사전 검증에 활용 가능. 실전 배포 전 백테스트 → 모의 → LIVE 3단계 거쳐야 함.
