## 항목별 검증 결과

### 1. U자형 패턴의 실전 일치성 ✅

- 09:00~10:00: 시초 주문 + 전일 재료 반영 → 거래량 급증
- 10:00~11:30: 재료 소화 → 거래량 완만
- 11:30~13:00: 점심시간 + 기관 휴식 → 거래량 감소
- 13:00~14:30: 오후 매수세 → 완만한 증가
- 14:30~15:30: 종가 앞 포지션 정리 → 거래량 재급증

박퀀트 Cubic Spline knot 5개(09:00, 10:00, 11:30, 13:30, 14:30) — **현장 감각과 정확히 일치**.

### 2. 14:30 급증 구간의 특수성 ⚠️

이 구간은 거래량 급증하지만 **당일 청산 대기 매도**가 주류이므로:
- 매수 진입은 매우 위험
- 매도(청산) 실행은 유동성 좋음

**권고**: 비선형 보정의 "기대 거래량" 함수는 **진입 판단용**과 **청산 판단용**을 분리 적용.

### 3. 피라미딩 진입 (Sprint 4) ⚠️⚠️

단타 실전에서 피라미딩은 두 가지 경우에만 수익성 있음:
1. **강한 상승 추세**에서 단계적 추가 진입 (정석)
2. **돌파 후 빠른 되돌림 없이 지속**하는 구간

**실패 패턴 (대부분의 경우)**:
- 첫 진입 후 추가 상승 → 피라미딩 진입 → 되돌림 → 손실 확대
- 특히 14:00 이후 피라미딩은 청산 시간 부족으로 **거의 항상 실패**

**최리스크 권고(+3% 이상, 30% 사이즈, 14:00 비활성화, 1주 모의)** 강력 지지.

**추가 권고**:
- 피라미딩 진입 직전 **호가창 확인 필수** (매수잔량 대비 매도잔량 비율 0.5+ → 돌파력 약함, 진입 금지)
- 이는 자동화 어려우면 **피라미딩 전면 보류** 검토

### 4. 2차 스크리닝 하이브리드 (Sprint 4) ✅

- 상대 70% + 절대 30% 적정
- 단, **절대 점수가 전일 대비 급락 종목**(예: -5% 이상)은 상대 순위와 관계없이 **제외** 필수

### 5. Phase 10 A/B 기간 ✅

- 1개월 관찰 적정
- 단, **장 국면 변화** 중이면 비교 무의미 (상승장 1주 + 하락장 3주면 변인 분리 불가)
- 권고: A/B 기간에 시장 VIX/코스피 변동성 로깅 → 국면 일정성 확인 후 비교

2. **14:30 U자형 패턴 오용**: 진입 강화로 해석하지 말고, 청산 유동성 확보로만 해석.
3. **실전 데이터 수집의 한계**: 개인 매매 환경은 기관 대비 호가 반영 지연 있을 수 있음. 지표 보정 시 고려.
