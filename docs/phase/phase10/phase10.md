## 개요

Phase 6.1의 선형 시간가중 보정(`adjusted_ratio = V / (V_prev * progress)`)을 **실제 관측 기반 U자형 비선형 보정**으로 교체한다. 한국 주식시장의 거래량 분포(U자형 — 시초·종반 급증, 중반 완만)를 반영하여 장 중반부의 보수적 편향(~10-20%)을 해소한다.

### 핵심 아이디어

```
현행 (선형): expected_volume(t) = V_prev * (t / T)
개선 (비선형): expected_volume(t) = V_prev * f(t)
  - f(t): 실제 관측된 시간대별 누적 거래량 비율 함수
  - 09:00~10:00 급등, 10:00~11:30 완만, 11:30~13:00 점심 둔화, 13:00~14:30 완만 증가, 14:30~15:30 재급증
```

### 범위 조정 (정프로 P1 반영)

**기존 4 Sprint → Phase 10은 3 Sprint로 집중**, Sprint 4(누적 백로그)는 **Phase 10.1로 분리**하여 범위 제어.

## 데이터 의존성 — 완화 불가 (Phase 9와의 경계)

> Phase 9는 사용자 지시 재검토로 "데이터 축적 대기 완화"가 가능했지만, Phase 10은 **완화 불가**이다.

### Phase 10이 Phase 9와 다른 이유

| 측면 | Phase 9 (Z-score/VWAP) | Phase 10 (U자형 비선형) |
|------|----------------------|----------------------|
| 주 목적 | 지표 계산 (단일 시점 통계량) | **모델 피팅** (함수 f(t)의 파라미터 추정) |
| 과거 데이터 대체 | KIS 백필로 초기 부트스트랩 가능 | ⚠️ KIS 백필은 "현재 국면" 데이터만 제공 (최대 30일) → 계절성/국면 변화 반영 불가 |
| 과적합 위험 | 낮음 | 매우 높음 (함수 형태 + 계수 동시 추정) |
| 검증 가능 표본 | 5~20일 초기 검증 가능 | 교차 검증 + 표본 외 테스트에 최소 2~3개월 필요 |

### 3가지 대안 검토

#### 대안 A: KIS 과거 장기 분봉으로 함수 피팅
- KIS 제약 최대 30일 → 3개월 요구에 부족
- **결론**: 기각. 단일 통계가 아닌 함수 피팅 목적이라 Phase 9와 다름.

#### 대안 B: 문헌 기반 초기 f(t) 고정 + 자체 데이터로 파인튜닝
- 학술 문헌(Admati & Pfleiderer 1988, Foster & Viswanathan 1990)의 U자형 일반 형태 활용
- 자체 축적 데이터로 knot/계수 조정
- **결론**: Sprint 1에서 **초기 출발점으로만 사용**. 3개월+ 축적 시 본격 자체 피팅.

#### 대안 C: 선형 보정 유지 + 슬롯별 상수 보정
- `adjusted_ratio = V / (V_prev * progress) * c(t)` 형태로 **시간대별 상수 c(t)만 학습**
- 함수 형태 추정 없이 슬롯별 평균 오차만 보정
- **결론**: 2개월(40거래일) 축적 시 적용 가능한 실용 안.

### 착수 조건 (정프로 P2 반영)

**Phase 9 Sprint 3 완료 + 2개월(40거래일) 축적 시 의무 착수** (지연 방지).

| 데이터 상태 | 착수 범위 | 최소 R² |
|-----------|---------|--------|
| Phase 9 + 2개월 | 대안 C (슬롯별 상수 보정)만 | N/A (상수이므로 피팅 아님) |
| Phase 9 + 3개월 | 대안 B + Cubic Spline 자체 피팅 | **0.85** |
| Phase 9 + 6개월 | 이상적 — 계절성 반영 + 완전 검증 | **0.90** |
