## 2. 항목별 검증 결과

### 매매 전략
- 모멘텀 브레이크아웃은 단타의 핵심 전략. MVP 단일 전략으로 적합.
- 핵심 진입 조건: **전일 고가 돌파 + 거래량 급증(직전 5분 대비 200%+) + 체결강도 70+**
- 이 3가지 조건이 동시 충족될 때 신호 생성. 하나라도 빠지면 신뢰도 급감.

### 진입/청산 상세 조건
- **진입**: 5분봉 기준 전일 고가 돌파 시 신호 발생 (종가 기준이 아닌 실시간 가격 기준)
- **청산**: 손절(-2%)/익절(+3%)/트레일링(-1%) 외에 **시간 기반 청산** 추가 필요
  - 진입 후 30분 경과해도 +1% 미달 시 보합 청산 (시장가)
  - 이유: 단타에서 "안 오르는 종목은 내린다"

### 시간대별 전략 차별화
- **09:00~09:30**: 관망 (시초가 변동성 과다, 허매수 많음)
- **09:30~10:30**: 골든타임 — 적극 매매, 신호 신뢰도 가중치 x1.2
- **10:30~14:00**: 일반 매매
- **14:00~14:30**: 신규 진입 축소 (청산 우선)
- **14:30~14:50**: 신규 진입 차단, 미청산 포지션 청산만
- **14:50~**: 강제 청산

### 주문 방식
- **시장가만 사용은 실전에서 위험**. 특히 소형주에서 슬리피지가 크다.
- **최우선 지정가(매수: 매도1호가, 매도: 매수1호가)** 권고.
- 한투 API에서 `ORD_DVSN = "01"` (시장가) 대신 호가 조회 후 `ORD_DVSN = "00"` (지정가) + 최우선 호가 사용.
- 체결 안 되면 3초 후 시장가로 전환 (2단계 주문 로직).

### 승인 타임아웃
- 장중 30초, 마감전 15초는 Phase 1 확정값이며 실전에서 적절.
- 단, 골든타임(09:30~10:30)에는 **20초로 단축** 권고. 기회 비용이 큼.

## 4. 리스크 및 대안

- **모의거래 체결 차이**: 모의에서는 시장가/지정가 체결 로직이 실전과 다름. 모의 환경에서는 시장가만 사용하되, 실전 전환 시 최우선 지정가로 변경하는 설정 분기 필요.
- **거래량 급감 시**: 거래량이 갑자기 줄면 브레이크아웃이 허위 신호일 가능성. 진입 후 1분 내 거래량이 절반 이하로 감소하면 즉시 청산 검토.
- **갭 상승 종목**: 장 시작 시 갭 상승 종목은 전일 고가 돌파가 의미 없음. 당일 시초가 기준으로 전환하는 로직 필요 (Phase 5 고도화).
