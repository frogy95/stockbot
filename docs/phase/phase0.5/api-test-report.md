### Rate Limit 실측

| 간격 | 결과 | 비고 |
|------|------|------|
| 토큰 발급 | 1분당 1회 | 초과 시 `EGW00133` |
| 시세 조회 (0.1초 간격) | 5회 연속 성공 | 공식 초당 1건보다 관대 |
| 에러 시나리오 연속 | Rate Limit 발생 확인 | `초당 거래건수를 초과하였습니다` |

**결론**: 공식 초당 1건이지만 실제로는 수 건 허용. 안전하게 **1.5초 간격** 권장.

### 에러 시나리오

| # | 시나리오 | HTTP | 응답 |
|---|---------|------|------|
| 1 | 잘못된 종목(999999) | 200 | 모든 값 0 (에러코드 없이 빈 데이터) |
| 2 | 만료/잘못된 토큰 | 500 | `EGW00121` 유효하지 않은 token |
| 3 | Rate Limit 초과 | 200 | `초당 거래건수를 초과하였습니다` |
| 4 | 장외 시세 조회 | 200 | 마지막 종가 데이터 정상 반환 |
| 5 | 장외 주문 | 200 | `모의투자 영업일이 아닙니다` (rt_cd=1) |

**주의**: 잘못된 종목도 HTTP 200을 반환하므로, `rt_cd`가 아닌 데이터 값 검증 필요.
