## 2. 항목별 검증 결과

### ⚠️ 한투 API 검증 항목 — 추가 필요

현재 계획에 포함된 항목은 적절하나, **문서와 실제가 다른** 주요 포인트를 반드시 확인해야 함:

**필수 추가 검증 항목:**
1. **hashkey 발급**: 주문 API에 필요한 hashkey 발급 절차 확인
2. **tr_id 매핑**: 모의/실전 tr_id 접두사 차이 확인 (VTTC vs TTTC 등)
3. **호가 단위**: 가격대별 호가 단위가 다름 — API 응답에서 확인
4. **장 상태 조회**: 현재 장 운영 상태(장전/장중/장후/휴장) 확인 API
5. **웹소켓 구독 형식**: 암호화 여부, 구독/해제 프로토콜 확인
6. **응답 인코딩**: EUC-KR/UTF-8 혼재 여부 확인

### ✅ 네이버 API 검증 항목 적절
- 뉴스 검색 정확도, 결과 품질 확인은 적절
- 추가 팁: `sort=date` vs `sort=sim` 비교, 검색 결과의 실시간성 확인

### ✅ DART API 검증 항목 적절
- 재무정보 + 공시 검색 범위 적절
- 추가 팁: 공시 데이터 지연이 보통 1~2시간 — 단타에 유용한지 판단 근거

### ✅ 텔레그램 API 검증 항목 적절
- 인라인 버튼 + 웹훅 테스트로 충분
- 추가 팁: 웹훅 설정 시 HTTPS 필수, 로컬 테스트는 ngrok 등 터널링 필요

### ⚠️ 탐색 스크립트 구조
- 각 API별 독립 스크립트로 작성 권고
- Jupyter Notebook보다 `.py` 스크립트 추천 (재실행, 자동화 용이)
- 단, 응답 구조 분석은 Notebook이 편리 — 혼용 가능

### ❌ 환경변수 설계 — .env.example 업데이트 필요
- 현재 `.env.example`에 한투 API 키, 네이버 API 키, DART API 키가 없음
- Phase 0.5 시작 전 `.env.example` 업데이트 필수

**필요한 환경변수 추가:**
```
# 한국투자증권 (모의)
KIS_MOCK_APP_KEY=
KIS_MOCK_APP_SECRET=
KIS_MOCK_ACCOUNT_NO=
# 한국투자증권 (실전)
KIS_APP_KEY=
KIS_APP_SECRET=
KIS_ACCOUNT_NO=
# 네이버 검색
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
# Open Dart
DART_API_KEY=
# Telegram
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

## 4. 리스크 및 대안

| 리스크 | 영향 | 대안 |
|--------|------|------|
| 한투 API 문서 부정확 | 높음 | 실제 호출로 검증, 응답 전체를 JSON으로 저장 |
| 모의거래 서버 불안정 | 중간 | 재시도 로직 포함, 장중/장후 각각 테스트 |
| 네이버 API 검색 품질 | 중간 | 종목명 + 종목코드 양쪽 검색 비교 |
| DART 공시 지연 | 낮음 | 단타 유용성 낮으면 Phase 2에서 제외 판단 |
| 텔레그램 웹훅 로컬 테스트 | 낮음 | ngrok/Cloudflare Tunnel 사용 |
