## 데이터 의존성 재검토 평가

### 1. 대안 A (KIS 백필) 기술적 검증 ✅

**쟁점**: KIS 과거 분봉 API가 제공하는 데이터와 실시간 체결 기반 거래량의 정합성.

**내 의견**:
- KIS `inquire-time-itemchartprice`는 체결 단위 거래량 제공 (시가/고가/저가/종가/거래량)
- buy/sell 분리는 제공하지 않을 가능성 높음 → total_vol Z-score만 백필 가능
- **수정주가 기준 거래량** 왜곡 가능성: 액면분할·유상증자 직후 종목은 제외 필요

**권고 구현 세부**:
```python
# 백필 제외 조건
if stock.had_split_within_30_days or stock.had_issuance_within_30_days:
    skip_backfill()
```

### 2. 대안 B (시뮬레이션) 기각 ✅ 완전 동의

"Phase 10이 검증하려는 U자형 가정 위에 Z-score 세우면 순환 논리" — 정확한 지적.

### 3. 대안 C (점진 활성화) 수학적 검토 ✅

제안된 가중치 0%/20%/50%/100%는 직관적이나, **표본 오차의 수학적 근거** 부족.

**제안 개선**: 표본 크기 n에 따른 **수학적 가중치 함수**
```
weight(n) = min(1.0, max(0, (n - 5) / 25))
  → n=5: 0%
  → n=10: 20%
  → n=20: 60%
  → n=30: 100%
  (선형 근사)
```

또는 **통계 유의성 기반**:
```
weight(n) = 1 - (σ_sample / σ_true_estimate)^2
  → 표본 표준편차가 추정 실제 표준편차에 수렴할수록 가중 상승
```

최리스크 권고(10/15/20/30 거래일)와 수렴. **최리스크 권고 채택**.

### 4. VWAP 즉시 착수 ✅

- 당일 장중 누적만 필요 → 재검토 결과 정확
- 실시간 계산 리소스: 종목별 `vwap:{code}:{date}` Redis 키에 `price*vol_sum`, `vol_sum` 누적 후 `ratio = price*vol_sum / vol_sum` → O(1)

Phase 8 리뷰에서 이미 제안. Phase 9에 통합 시:

### 6. 지표 상관관계 주의 ⚠️

5분봉 가속도 + Z-score + VWAP 가격 포지션 — **모두 거래량 기반**. confidence 프레임워크에 단순 합산 시 **동일 정보에 가중치 중복 부여** 가능.

**권고**: Sprint 1·2에서 지표 상관관계 계산 → 상관계수 > 0.7 쌍이 발견되면 가중치 축소 또는 통합.
