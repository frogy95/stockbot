# Phase 9 검토 리포트 — 최리스크 (리스크관리)

> **검토일**: 2026-04-20
> **검토 대상**: `docs/phase/phase9/phase9.md`
> **검토 관점**: 통계적 신뢰 부족 시 리스크 / 조기 활성화의 위험

---

## 요약

⚠️ **주의** — 데이터 의존성 재검토는 타당하나, **조기 활성화가 전략 신뢰도를 실제 성과로 검증하기 전에 매매 결정에 영향**을 미치는 점이 위험. 점진 활성화 구간에서 **로깅 전용 구간을 더 길게** 유지 권고.

---

## 항목별 검증 결과

### 1. 점진 활성화 가중치 구간 ⚠️

제안된 구간:
| 축적 일수 | Z-score 가중치 |
|----------|--------------|
| < 5거래일 | 0% (로깅만) |
| 5~10거래일 | 20% |
| 10~20거래일 | 50% |
| 20거래일+ | 100% |

**우려**: 5거래일은 통계적으로 매우 부족. 평균·표준편차의 표본 오차가 크고, 이에 따른 Z-score 오탐이 실제 매매 결정에 20% 영향을 미치면 손실 가능성 증가.

**권고 재조정**:
| 축적 일수 | Z-score 가중치 |
|----------|--------------|
| < 10거래일 | **0% (로깅만)** |
| 10~15거래일 | **10%** |
| 15~20거래일 | **30%** |
| 20~30거래일 | **60%** |
| 30거래일+ | **100%** |

즉, **로깅 전용 구간을 10일로 연장**, 가중치 100%는 30일부터. 박퀀트와 협의.

### 2. KIS 백필 데이터의 신뢰성 ⚠️

박퀀트 리뷰의 우려(현재 수집 체결 기반과 스케일 차이)를 공유. 리스크 관점에서:
- 백필 데이터 기반 Z-score가 **실시간 데이터 기반 Z-score보다 체계적으로 편향**되면 → 활성화 초기에 일관된 오탐 발생 가능

**권고**: 백필 데이터와 실시간 축적 데이터의 **통계 비교 검증** 필수. 차이 10% 이상 시 백필 데이터 제외 + 재검토.

### 3. VWAP 기반 전략 반영 ✅ (조건부)

- ±0.005 임계값 (0.5%) 적정
- 가중치 ±0.05 적정 (과도 반영 아님)

**단, 리스크**: VWAP는 장 초반에는 몇 분 거래로 크게 흔들림. **장 시작 후 30분은 VWAP 지표 비활성화** 필수.

### 4. 백테스트 데이터셋 (Sprint 3) ⚠️

- 백테스트 결과가 좋다고 실전 배포하는 패턴 경계
- 반드시 **표본 외(out-of-sample) 테스트**와 **실전 모의거래 병행 검증** 요구

## 리스크 및 대안

1. **조기 활성화 구간의 오탐 영향**: confidence 가중치가 최대 ±0.10까지 커지면 매매 결정에 영향 확실. 초기 가중치 축소로 리스크 완화.
2. **KIS 백필의 체계적 편향**: 발견 시 즉시 백필 데이터 제외하는 롤백 경로 문서화 필수.

## 결론

재검토 방향 타당. 단, **로깅 전용 기간 연장 + 가중치 완만한 상승 + 백필 데이터 사전 검증**이 반드시 반영되어야 리스크 수용 가능.
