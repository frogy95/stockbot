## 2. 항목별 검증 결과

### 스케줄러 관리 페이지
- **위치**: 기존 사이드바에 "시스템" 메뉴 추가
- **정보 구조**:
  1. 파이프라인 상태 카드 (healthy/unhealthy + 마지막 성공 시각)
  2. 각 스케줄 job 상태 (성공/실패/미실행 + 다음 실행 시각)
  3. 수동 트리거 버튼 그룹

### 수동 트리거 버튼 UX
- **권고**:
  - "장전 전체 재실행" 버튼은 크고 눈에 띄게 (Primary 스타일)
  - 개별 단계 트리거는 Secondary 스타일로 접을 수 있는 섹션에 배치
  - 실행 중에는 버튼 비활성화 + 스피너 + "실행 중..." 텍스트
  - 완료 후 성공/실패 결과 토스트 알림
- **위험 방지**: "장전 전체 재실행"은 확인 다이얼로그 포함 ("장전 데이터를 다시 수집합니다. 실행하시겠습니까?")

### 파이프라인 상태 시각화
- **권고**: 스텝 인디케이터 (Stepper) 패턴
  ```
  [장전수집] → [ETF마스터] → [1차스크리닝] → [ETF시세] → [DART] → [센티멘트]
    ✅ 08:01    ✅ 08:11      ❌ 실패         ⬜ 미실행   ⬜ 미실행   ⬜ 미실행
  ```
- 실패 단계는 빨간색 배경 + 에러 메시지 툴팁
- 성공 단계는 녹색 체크 + 실행 시각

### 색상 체계
- 파이프라인 건강: `#16A34A`(녹색, healthy) / `#DC2626`(빨간색, unhealthy)
- Phase 4 설정 페이지의 색상 체계와 일관성 유지

## 3. 파라미터 조정 권고

| 항목 | 원래 설계 | 권고값 | 근거 |
|------|----------|--------|------|
| 트리거 확인 다이얼로그 | 없음 | **"장전 전체 재실행"에만 확인 필요** | 오클릭 방지, 개별 트리거는 확인 불필요 |
