## 2. 항목별 퀀트 검증

### A. volume_ratio 임계값 (2.0 → 1.5)
- **통계적 근거**: 전일 대비 200% 이상은 상위 약 5~10%에 해당하는 극단적 기준. 일반적으로 거래량 이상 탐지는 1.5~2.0 표준편차(약 130~150%) 수준을 사용.
- **1.5 적정성**: 전일 대비 150%는 약 1.5 표준편차 수준으로 통계적으로 유의미한 이상치 판별 기준.
- **개선 제안**: 고정 임계값보다 rolling z-score 기반이 이상적이나, MVP 단계에서는 고정값 1.5가 합리적.
- **장기 개선**: 2주 운영 데이터 축적 후 실제 분포 분석하여 임계값 보정 권고.

### B. 적응형 필터 — 백분위 왜곡 분석
- **핵심 문제**: scorer.py의 _calc_percentiles()는 rank/total*100으로 백분위를 계산. 후보군 크기(total)에 따라 백분위 분포가 달라짐.
  - 후보 100개: 상위 1위 = 100점, 하위 1위 = 1점
  - 후보 10개: 상위 1위 = 100점, 하위 1위 = 10점 → 하위 종목도 높은 점수
  - 후보 5개: 하위 1위 = 20점 → 매우 높은 바닥 점수
- **리스크**: 적응형으로 후보가 줄어들면 모든 후보의 점수가 상향 편향 → pass_threshold=60.0을 쉽게 통과
- **권고**:
  1. 적응형 필터로 후보가 변동할 때 pass_threshold를 동적으로 조정하거나
  2. **더 단순한 대안**: 적응형 결과에 별도 플래그를 부착하고, 임계값은 고정 유지 (현재 구조 유지)
  3. 후보 10개 미만 시 백분위 대신 절대값 기반 스코어링으로 전환 검토 (Phase 6)

### C. prev_volume=0 폴백 — 통계적 유의성
- **문제**: prev_volume=0인 319건은 두 가지 경우:
  1. T-2 데이터 부재 (초기 배포/장애 복구) — 대다수
  2. 실제로 전일 거래량이 0 (거래 정지 종목)
- **5일 평균의 한계**: 거래 정지 해제 직후 종목은 5일 중 대부분이 0이므로 평균도 0에 가까움 → 사실상 탈락
- **권고**: 5일 평균 대체는 합리적이되, **유효 거래일 3일 이상** 조건 필요 (최리스크와 동의)
- **volume_ratio 해석**: 폴백 평균 대비 volume_ratio는 "정상 거래량 대비 오늘 변화"로 해석 가능 — 통계적으로 유의미

### D. 0건 시 기본 후보 — 팩터 스코어링 왜곡
- **심각한 우려**: 기본 후보(시총+거래량 상위)는 volume_ratio 기반 선별을 거치지 않음.
  - volume_factor: 시총 상위 대형주는 거래량 변동이 작아 volume_factor가 낮음
  - momentum_factor: 대형주는 단기 모멘텀이 약한 경향
  - 결과: 기본 후보의 스코어가 체계적으로 낮아짐
- **하지만**: 이 종목들은 유동성이 높아 체결/슬리피지 리스크는 낮음
- **권고**:
  1. 기본 후보는 스코어링을 거치되, 별도 카테고리로 분류 ('fallback')
  2. 2차 스크리닝에서 실시간 데이터로 재검증
  3. 기본 후보의 pass_threshold를 높이거나 (70.0 등) 또는 skip
  4. **가장 현실적 대안**: 기본 후보는 스코어링 없이 직접 2차 스크리닝 투입 (1차 스코어링 무의미하므로)

## 4. 스코어링 품질 영향 분석

- **적응형 필터 후 후보 10~30개**: 백분위 왜곡 허용 범위. pass_threshold 60.0에서 하위 40% 탈락은 유지됨.
- **적응형 필터 후 후보 5개 미만**: 백분위 의미 상실. 이 경우 전원 통과가 현실적 — 5개 미만은 그 자체로 희귀.
- **기본 후보 15~20개**: 팩터 분포가 일반 후보와 상이 → 혼합 스코어링 시 왜곡. 분리 처리 필수.
