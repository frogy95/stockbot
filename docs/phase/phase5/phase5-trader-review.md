## 2. 항목별 실전 매매 관점 검증

### A. volume_ratio 완화 (2.0 → 1.5)
- **실전 감각**: 전일 대비 150% 거래량은 분명히 "무언가 일어나고 있다"는 신호.
  - 200%는 이미 급등/급락이 진행 중인 종목 위주 — 진입 시점이 늦을 수 있음
  - 150%는 아직 초기 단계의 관심 종목을 포착 — 오히려 진입 타이밍이 좋을 수 있음
- **추가 관점**: 조용한 장(박스권, 관망 장세)에서는 전체 시장 거래량이 줄어들어 200%를 충족하는 종목이 극소수. 1.5가 현실적.
- **이상적**: 장세에 따라 임계값을 동적으로 조정하면 최고지만, MVP에서는 고정 1.5 합리적.

### B. 적응형 필터 — 단타 기회 관점
- **volume_ratio 1.2 (120%)**: 전일보다 20% 증가 — 약한 신호지만 다른 팩터(모멘텀, 변동성)와 결합하면 의미 있음.
- **volume_ratio 1.0 (100%)**: 전일과 동일한 거래량 — 거래량 증가 신호가 전혀 없음. **단타에서 거래량 증가 없는 종목은 진입 근거가 약하다.**
  - 대세 하락장에서 방어적으로 대형주를 매매하는 경우가 아니면, 거래량 동일 종목에서 단타 기회를 찾기 어려움.
- **권고**: 최리스크, 박퀀트와 동의 — **최저 1.2로 제한**.

### C. prev_volume=0 폴백
- **실전 관점**: 전일 거래량 0인 종목 = 거래 정지 해제 또는 신규 상장.
  - 거래 정지 해제 직후: 극단적 변동성 (상한가/하한가 가능) — 단타 기회이지만 리스크 극대
  - 신규 상장: 가격 변동 패턴 예측 어려움
- **5일 평균 대체**: 합리적. 단, 실제 거래 정지 종목(5일 모두 0)은 자연스럽게 탈락 — 안전.
- **조건**: 유효 거래일 3일 이상 동의.

### D. 0건 시 기본 후보 — 대형주 단타 효율
- **현실**: 삼성전자, SK하이닉스 등 시총 상위 종목은 일중 변동폭이 1~2% 수준.
  - 손절 -2%, 익절 +3% 기준에서 익절 도달이 어려움
  - 호가 스프레드는 좁아 체결은 좋지만, 수익 기대가 낮음
- **단타 효율 높은 대안**: 거래량 상위(시총 무관)가 더 나은 후보. 코스닥 중소형주 중 거래량 상위가 단타 기회가 많음.
- **권고**: 기본 후보 선정 기준을 "시총 상위 + 거래량 상위" → **"거래량 상위 15개 (시총 500억 이상)"**로 변경.
  - 거래량 상위 = 당일 이미 활발한 종목 = 단타 기회 존재
  - 시총 하한은 기존 market_cap_min(500억) 유지하여 초소형주 제외

### E. Sprint 순서
- **절대적으로 Sprint 1(스크리닝 안정화) 선행**: 스크리닝이 0건 나오는 시스템에 완전 자동을 붙이면 아무 의미 없음.
- **Sprint 2(완전 자동) 전 관찰 기간**: 최소 3~5거래일 운영 관찰 후 착수 권고.
- **Sprint 3(성과 분석)**: Sprint 2와 병행 가능하지만, 매매 데이터가 쌓여야 의미 있으므로 순서 적절.

## 4. 매매 품질 영향 분석

- **volume_ratio 1.5**: 후보 풀 확대 → 2차 스크리닝(실시간 체결강도/호가잔량)에서 걸러지므로 최종 매매 품질 유지
- **적응형 1.2**: 조용한 장에서도 최소 후보 확보 → 2차에서 걸러지더라도 "매매 불능" 상태 해소
- **기본 후보**: 거래량 상위로 변경하면 단타 가능 종목 비율 상승 — 다만 스코어링 없이 2차 직접 투입이 현실적 (박퀀트 의견 동의)

## 5. 리스크 및 대안

- **리스크**: 적응형으로 후보 품질이 낮아져도 반자동 모드에서 사용자가 최종 판단하므로 실질 리스크 제한적
- **완전 자동 시**: 적응형/기본 후보는 절대 자동 주문 금지 (최리스크 의견 강력 동의)
- **장세 판별**: Phase 6로 이관 동의. 코스피/코스닥 등락률 기반 동적 임계값은 효과적이지만 구현 복잡도 높음.
