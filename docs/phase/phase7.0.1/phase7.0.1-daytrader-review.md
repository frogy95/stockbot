## 2. 항목별 검증 결과

### 장애가 매매에 미치는 영향

**시초가 30분 (09:00~09:30)**:
- 전체 일일 거래량의 약 20~30%가 집중
- 단타 매매의 핵심 진입/청산 구간
- WS 미연결 = 이 구간 완전 무방비 → 오늘 매매 기회 전면 상실

**장중 (09:30~15:00)**:
- 2차 스크리닝 30초 주기도 WS 의존 → 전면 중단
- 기존 포지션이 있다면 실시간 가격 감시 불가 (단, Phase 7.0에서 수정 완료)

**다행인 점**:
- 현재 LIVE 포지션 없음 (Phase 7.0 Sprint 3 미완료로 LIVE 미전환)
- WS 미연결 시 매매 진입 자체가 차단 → 손실 리스크 0

### 복구 타이밍 분석

| 시각 | 의미 | 비고 |
|------|------|------|
| 당일 15:30 | 장 마감 | 오늘 복구해도 장중 매매 불가 |
| 익일 08:00 | 장전 수집 시작 | 이때까지 WS 수정 완료 필요 |
| 익일 08:50 | WS 연결 준비 | 장전 수집 완료 후 WS 연결 시도 |
| 익일 09:00 | 장 시작 | ws_connected=True 필수 |

→ **오늘 중 수정 배포 완료, 내일 09:00에 자동 연결 성공이 목표**

### PAPER 환경 보호 중요성

- PAPER 환경은 현재 유일한 E2E 테스트 환경
- Phase 7.0 Sprint 3의 E2E 검증이 PAPER에서 진행 예정
- PAPER를 깨뜨리면 Sprint 3 자체가 블로킹

## 4. 리스크 및 대안

1. **내일 장 전 미해결 시**: 수동 복구 API로 WS 재연결 시도. 실패 시 내일도 매매 불가.
   - 대안: PAPER로 전환하여 모의거래라도 E2E 검증 진행
2. **LIVE WS 연결 성공해도 구독 실패**: approval_key나 구독 메시지 형식 문제 가능
   - 대안: diagnose_ws.py 확장하여 구독까지 테스트
3. **KIS 서버 점검**: 드물지만 KIS가 WS 서버 점검 중일 수 있음
   - 확인: KIS 공지사항 또는 고객센터 확인
