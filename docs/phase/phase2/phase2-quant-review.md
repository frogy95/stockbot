## 항목별 검증 결과

### 1. 팩터 선정 (✅)

5개 팩터 (거래량, 변동성, 모멘텀, 체결강도, 호가잔량)는 단타 스크리닝에 적합. 팩터 수 5개는 과적합 위험 낮음.

### 2. 팩터 간 상관관계 주의 (⚠️)

거래량-체결강도 상관이 높을 수 있음 (실전 데이터 상관계수 0.5~0.7 예상). 그러나 MVP에서는 동일 가중으로 시작하고, 운영 1개월 후 상관관계 분석 → 가중치 조정이 적절.

### 3. 정규화 방식 (⚠️ -> 순위 기반 백분위 권고)

- Z-score: 이상치에 민감 (급등주가 전체 분포 왜곡)
- Min-Max: 범위 변동에 취약
- **순위 기반 백분위**: 이상치 강건, 분포 가정 불필요 → 권고

```
score = (rank / total_count) * 100
```

### 4. 모멘텀 팩터 정의 (⚠️)

단타 특성상 장기 모멘텀(20일)은 부적합. **3일 단기 수익률** 권고:
```
momentum_3d = (close_today - close_3days_ago) / close_3days_ago * 100
```
5일도 가능하지만 3일이 단타 회전율에 더 적합.

### 5. 변동성 팩터 정의

**ATR(Average True Range) 5일** 권고:
```
TR = max(high - low, abs(high - prev_close), abs(low - prev_close))
ATR_5 = SMA(TR, 5)
```
높은 ATR = 높은 변동성 = 단타 기회. 단, 과도한 변동성은 리스크 → 상위 10% 제외 필터 고려.

### 6. ETF 전용 팩터 (⚠️)

- **괴리율**: 장중 실시간 계산 가능 (한투 API 제공). 1차 포함 적절.
- **NAV 프리미엄**: 실시간 NAV 데이터 취득 어려움 → Phase 5 이후.
- ETF는 재무 팩터(매출/영업이익) 미적용 → 거래량, 변동성, 모멘텀, 체결강도, 괴리율 5개 팩터.

## 리스크 및 대안

- 팩터 유효성 검증: 운영 초기 1주간 스크리닝 결과 vs 실제 수익률 상관관계 모니터링 권고

- 재무 데이터 미제공 종목: 해당 팩터 중립값(50 백분위)으로 처리
