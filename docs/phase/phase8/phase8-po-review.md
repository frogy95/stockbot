### 2. 병행 원칙 재검토 ⚠️

기존 문서에 "Sprint 3·4는 Sprint 1·2와 병행 가능"으로 기술했으나 **1명 개발자 제약**에서 병행은 사실상 컨텍스트 스위칭 비용이 크다. 현실적 순서:

```
Sprint 1 (1~2일) → Sprint 1 배포 + 2거래일 관찰
  → 분기:
     [신호 발생 OK + 품질 충분] → Phase 7.0 Sprint 3 (E2E) 즉시 재개
                              → 병행으로 Sprint 3·4 시작
     [신호 발생 OK + 품질 부족] → Sprint 2 (다층 진입)
                              → Phase 7.0 Sprint 3 재개
                              → Sprint 3·4 순차
     [신호 여전히 0건] → Sprint 2 필수 + 다른 근본 원인 재조사
```

### 3. Sprint 5 착수 시점 재평가 ⚠️

- Phase 6.1 Sprint 1 배포일: 2026-04-13
- 20거래일 축적 예상: 2026-05-12
- Sprint 1~4 예상 완료: 2026-04-30~05-05 (1주+)
- **즉, Sprint 5 착수 시점 도달 전에 Sprint 1~4 대부분 완료** → 계획상 무리 없음

단, **Phase 9 재검토 결과가 "KIS 백필로 축적 대기 회피"이므로 Sprint 5의 위치도 재고 필요**. 박퀀트와 상의하여 Sprint 5를 Phase 9로 통합할지 결정해야 한다.
