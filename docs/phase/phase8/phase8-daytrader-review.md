## 요약

✅ **통과** (Sprint 1·2) / ⚠️ **주의** (Sprint 5) — Sprint 1·2는 실전 매매 복구의 정공법. Sprint 5의 "5분봉 가속도"는 단타에서 유효하지만 착수 시점과 지표 사용 방식에 실전 주의사항 있음.

---

## 항목별 검증 결과

### 1. Sprint 1 (OHLC 파싱) ✅

- **H0STCNT0에 OHLC 이미 포함된 걸 파싱 안 하고 있었다는 사실**이 가장 중요. 실전에서는 시가/고가/저가 없이는 단타 판단 자체가 불가능.
- 갭 분기 `breakout_ref = open_price` 변경 — **현장 표준**: 갭 상승 후 시가 위 유지 여부로 재료의 지속성 판정.

**경고**: Sprint 1 배포 후 첫날 **Redis 값 직접 확인** 필수. idx 매핑 오류는 현장 실전에서 자주 발생 (특히 KIS WS는 필드 추가 시 idx 바뀔 때 있음).

### 2. Sprint 2 (다층 진입) ✅

- prev_close 돌파 + 반 포지션 + confidence 상한 0.75 → **단타 실전의 표준 패턴**
- 13:00 이후 prev_close 비활성화 → **핵심 안전장치**. 14:50 청산 시 prev_close 돌파 후 반등 시간 부족.
- 일일 10건 한도 → 데이트레이딩 평균선. 과도한 회전 방지.

### 3. Sprint 3 (관리 UI) — 코멘트

실전 운영 관점에서 **추가 요청**:
- **현재 보유 포지션 실시간 현황** 카드 (시가, 현재가, PnL %, 경과 시간)
- **당일 청산 예정 시각 카운트다운** (14:50 기준)
- **장 단계 표시** (장전/장중 시초/장중/마감 30분 이전/마감 임박)

이 3가지 없이는 운영자가 수동 개입 시점 판단 불가.

### 4. Sprint 4 (성과 분석) — 코멘트

**단타 특유의 추가 지표 요청**:
- **매매 건당 평균 보유 시간** (단타의 핵심 지표)
- **승률 vs 평균 수익률 산포도** (Sharpe보다 직관적)
- **시간대별 진입 분포** (시초/오전/점심 전/오후)

### 5. Sprint 5 (5분봉 가속도) ⚠️

**실전 유효성**: 매우 높음. 단타 경험상 거래량 가속도는 "진짜 재료"와 "가짜 돌파" 구분의 핵심.

**하지만 주의사항 4가지**:

1. **장 시초 30분**: 거래량이 항상 급증하므로 "가속"이 무의미. Sprint 5 지표는 **09:30 이후에만 활성화** 필수.
2. **점심시간(11:30~13:00)**: 거래량이 자연 감소. 이 시간대의 "감속"을 신호 약화로 해석하면 오탐 증가.
3. **장 막바지(14:30~)**: 거래량이 다시 급증. "가속" 신호가 오히려 위험 (당일 청산 압박).
4. **종목 유동성 차이**: 일평균 거래량 100만 주 이하 종목은 슬롯당 거래량이 0인 경우 흔함 → Z-score 오탐.

**권고**: Sprint 5 구현 시 **시간대별 가중치 스케일링** 필수:
- 09:30~10:30: 가중치 0.5 (시초 노이즈)
- 10:30~11:30: 가중치 1.0 (유효 구간)
- 11:30~13:00: 가중치 0.3 (점심 둔화)
- 13:00~14:30: 가중치 1.0 (유효 구간)
- 14:30~: 지표 비활성화 (막바지 리스크)

## 리스크 및 대안

1. **Sprint 1 배포 당일 검증 실패 가능성**: idx 매핑 오류 시 즉시 롤백. 초기 1~2시간 모니터링 필수.
2. **Sprint 2 없이 LIVE 전환 리스크**: prev_close 돌파 없이 prev_high만으로는 여전히 신호 희소. 최리스크 권고(3건/일 제한) 지지.
3. **Sprint 5 "가속도 가중 +0.05"가 확실히 도움이 되는지**: Phase 9에서 버림받을 수 있음. 초기에는 **로깅만** 권고.

## 결론

Sprint 1·2는 즉시 착수하는 것이 맞다. Sprint 3·4에 단타 특화 지표 추가 권고. Sprint 5는 시간대별 가중치 + 유동성 필터 없이는 오히려 노이즈. Phase 9로 이관하여 VWAP와 함께 통합 설계 권고.
